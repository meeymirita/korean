Шрифты для листов, которые рисует сервер (недельный отчёт по занятиям, backend/src/study/weekly-pdf.ts).
В образе сервера системных шрифтов нет, поэтому файлы лежат здесь и попадают в образ (COPY assets в docker/backend/Dockerfile).

Archivo-Regular.ttf, Archivo-SemiBold.ttf, Archivo-Bold.ttf: github.com/Omnibus-Type/Archivo (fonts/ttf), SIL Open Font License 1.1.
NotoSansKR-Regular.otf, NotoSansKR-Bold.otf: github.com/notofonts/noto-cjk (Sans/SubsetOTF/KR), SIL Open Font License 1.1.
