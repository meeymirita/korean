# 우리말 — корейский язык

> **Живой сайт:** https://korean.meeymirita.ru

**우리말** (по-корейски «наш язык», «родной язык») — личная платформа для изучения корейского с нуля: словарь, грамматика, игры, повторение по интервалам, заметки и прогресс в одном спокойном месте. Выросла из занятий по курсу 서울대 한국어+ 1A и видеокурсу, материал ведётся вместе с учителем.

## Для чего и для кого

- **Учиться каждый день понемногу.** «Сегодня» собирает слова дня, правило и задания, «Повторение» напоминает, что пора освежить, цель дня и серия мягко возвращают завтра.
- **Только пройденное.** Сайт не забегает вперёд: темы, которые ещё не проходили, в заданиях не появляются.
- **Без звука и без лишнего.** Упор на чтение, письмо, правила и практику; пастельный тихий вид, без рекламы.
- **Открытое и закрытое.** Справочники (слова, грамматика, шпаргалка, разговорник, хангыль, алфавит, чтение, примеры, числа) открыты всем. Задания, игры, повторение и кабинет работают по токену; для гостей есть временные ссылки, которые ничего не сохраняют.

## Что внутри

- **645 слов** по 12 темам: чтение русскими буквами, перевод, пример с разбором по словам и частицам; мини-уроки о культуре Кореи.
- **61 правил грамматики** карточками с формулами, таблицами, примерами, видеоуроками и картинками; «Что я уже знаю» собирает пройденное на одной странице, «Мастерская» показывает конструктор предложений и логику правил.
- **Игра «Хлебушек» и тренажёры:** 33 режима (перевод, частицы, место, числа и деньги, время, формы глаголов, «собери предложение», «найди ошибку», блиц и выживание, печать на корейской клавиатуре); на любой карточке грамматики кнопка «Потренировать правило».
- **Разбор ошибок.** После неверного ответа объяснение «что выбрано, как верно и почему» и ссылка на нужную карточку правила.
- **Прогресс:** 40 уровней, серия дней, цель дня, сад воспоминаний и коллекция карточек, достижения, итоги недели, отчёт с графиками, монетки и магазин, напоминания в Telegram.
- **Кабинет:** профиль и обложка, заметки с картинками, галерея, календарь с файлами, таймер занятий, светлая, тёмная и ночная темы.
- **Поиск** по всему сайту окном (Ctrl/⌘ + K); прежний поиск главный, Meilisearch добавляет найденное с опечатками.
- **Для владельца:** страница «Сервисы» (состояние контейнеров, журналы, поисковый индекс, отчёт для разбора неполадок, ссылки на Grafana и Prometheus), копии и защита (код входа из Telegram, повторный токен для опасных действий), вкладка «Telegram» с проверкой уведомлений.

## Стек

| Часть | Что |
|---|---|
| Сайт | Nuxt 4 (отрисовка на сервере), Vue 3, TypeScript, Pinia |
| Сервер | NestJS 12, Prisma, PostgreSQL 17 |
| Очередь и поиск | Redis (BullMQ: уведомления и копии), Meilisearch |
| Мониторинг | Prometheus, node-exporter, Grafana (панель «нагрузка и состояние») |
| Запуск | Docker Compose, вход через Caddy |
| Выкладка | GitHub Actions: пуш в `main` → проверки → автоматический `deploy.sh` на сервере |

## Быстрый старт

Нужен Docker с Compose v2.

```sh
bash scripts/init-env.sh            # создаёт .env со случайными паролями и токеном входа
docker compose up -d --build        # сайт http://127.0.0.1:3000, API http://127.0.0.1:3001
```

Токен входа лежит в `.env` (`PROGRESS_TOKEN`). Копии, мониторинг и поддомены: [`docs/docker.md`](docs/docker.md).

Разработка без Docker для сайта: Node 22.18+ или 24.12+, PostgreSQL, Redis (по желанию):

```sh
npm ci && npm --prefix frontend ci && npm --prefix backend ci && npm --prefix backend run db:generate
npm run server:dev     # API на 127.0.0.1:3001 (нужен DATABASE_URL)
npm run dev            # сайт на http://localhost:3000, /api проксируется на сервер
```

## Тесты и выкладка

`npm test` собирает сервер и запускает все проверки (около 700 тестов: игра, данные, сервер на настоящей PostgreSQL, скрипты выкладки и копий); `npm run type-check`, `npm run build`. Как поднять PostgreSQL, Redis и Meilisearch для тестов: последний раздел `docs/docker.md`.

На каждый пуш в `main` GitHub запускает те же проверки и сборку образов, а при зелёном результате сам выкладывает сайт на сервер: `scripts/deploy.sh` делает копию базы, собирает образы, перезапускает службы и сам откатывается, если сайт не ответил. Вручную на сервере: `cd /var/sites/korean && bash scripts/deploy.sh`.

## Устройство репозитория

```
frontend/   сайт (Nuxt): src/pages, views, components, stores, data, game, assets
backend/    сервер (NestJS + Prisma): src, prisma (схема и миграции), scripts
docker/     Dockerfile сайта и сервера, Caddyfile для профиля edge, Prometheus, Grafana (панель)
tests/      тесты проекта (node --test); у frontend/ и backend/ свои тесты фреймворков
scripts/    выкладка, копии, сборка словарей и вспомогательные утилиты
docs/       документация по темам
```
