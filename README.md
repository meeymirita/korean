# 우리말 — корейский язык

> **Живой сайт:** https://korean.meeymirita.ru

**우리말** (по-корейски «наш язык», «родной язык») — личная платформа для изучения корейского языка с нуля. Это не набор разрозненных
страниц, а одно спокойное место, где можно учить слова и грамматику, повторять по интервалам, играть в игры на слова, вести заметки с
картинками, следить за прогрессом и временем занятий и ничего не искать по другим сайтам. Платформа выросла из занятий по курсу
서울대 한국어+ 1A и видеокурсу, а материал ведётся вместе с учителем.

## Для чего и для кого

- **Учиться ежедневно по чуть-чуть:** «Сегодня» собирает слова дня, правило и задания, «Повторение» напоминает, что пора освежить, цель дня и серия
  занятий мягко возвращают завтра.
- **Только пройденное:** сайт не забегает вперёд. Уроки и формы, которые ещё не проходили (например, будущее время), в заданиях не появляются.
- **Без звука и без лишнего:** никакой озвучки; упор на чтение, письмо, правила и практику. Вид пастельный и тихий, без рекламы и счётчиков.
- **Своё пространство:** личный кабинет с профилем и обложкой, заметки, галерея картинок, таймер занятий, достижения, сад и коллекция карточек.
- **Открытое и закрытое:** справочники (слова, грамматика, шпаргалка, разговорник, хангыль, алфавит, чтение, примеры, числа) открыты всем, а задания,
  тренажёры, игра, повторение и кабинет работают после входа по токену; для гостей есть временные ссылки, которые ничего не сохраняют.

## Что внутри

- **528 слов** по 11 темам с чтением русскими буквами, переводом и примером, который разбирается по словам и частицам.
- **43 правил грамматики** карточками: формулы, таблицы, примеры, пройденное отмечено.
- **Справочник из 7 вкладок**, тренажёры («найди пару», «напиши перевод»), **игра «Хлебушек» с 15 режимами**, блицем и выживанием.
- **Прогресс:** 40 уровней, серия дней, цель дня, статистика по словам, сад воспоминаний, коллекция карточек, 15 достижений, итоги недели.
- **Поиск по всей платформе** в одном окне (Ctrl/⌘ + K) без переходов, заметки с картинками, свои картинки, таймер занятий.
- **Надёжность:** сервер с базой SQLite, ежедневные копии базы и зашифрованный полный архив на почту, защита от подбора токена, повторный токен для опасных действий, таймауты, SEO и готовые страницы для поисковиков.

### Доступ по токену

Справочники открыты всем: слова, грамматика, шпаргалка, разговорник, хангыль, алфавит, правила чтения, примеры, числа.
Опасные действия (сброс прогресса, загрузка копии, создание гостевого токена) просят токен ещё раз.
Задания «Сегодня», тренажёры, повторение, игра и «Мой кабинет» открываются после ввода токена (он тот же, что в
`server/.env`). Пока токен не введён, в меню рядом с этими разделами замок, а на их страницах поле для токена.
На каждом устройстве токен вводится один раз; «Выйти» в кабинете → «Настройки» закрывает доступ на этом устройстве.

### Прогресс и сервер

Каждый верный ответ (игра, тренажёры, «Сегодня») даёт очки; слово считается выученным после трёх верных ответов
подряд. Всё, что вы делаете (ответы, профиль, настройки, заметки, картинки, гостевые токены), хранится в базе SQLite на
сервере: `server/data/app.db`. Сайт показывает прогресс сразу, а на сервер действия уходят через секунду; без сети они
копятся в браузере и отправляются позже. Подробное устройство сервера: `docs/server.md`.

Запуск (нужен Node 22.18 или новее, 24 лучше):

1. Установи зависимости сервера один раз: `npm --prefix server ci`.
2. Создай токен (пароль для входа) и положи в `server/.env`:
   ```sh
   echo "PROGRESS_TOKEN=$(openssl rand -base64 24)" > server/.env
   cat server/.env        # покажет токен, он понадобится на сайте
   ```
   Или скопируй `server/.env.example` в `server/.env` и впиши свой токен. Файл `server/.env` в git не попадает.
3. Собери и запусти: `npm run server:build`, затем `npm run server` (слушает `127.0.0.1:3001`). В разработке:
   `npm run server:dev` (перезапускается при правках) и в другом окне `npm run dev`, Vite сам проксирует `/api`.
4. На хостинге сервер работает как служба systemd (см. `docs/hosting.md`), а наружу его выставляет Caddy:

```
example.ru {
    handle /api/* {
        reverse_proxy 127.0.0.1:3001
    }
    handle {
        root * /путь/к/проекту/dist
        try_files {path} {path}/index.html /index.html
        file_server
    }
}
```

После правки Caddyfile: `caddy reload`. Если на сайте пишет «неверный токен», токен не совпадает с `server/.env`; если
«сервер недоступен», не запущен сервер или нет блока `handle /api/*` в Caddy. Папка `server/data/` не коммитится.

Тесты: `npm test` (собирает сервер и запускает все проверки, больше двухсот).

Защита сервера (заголовки, блокировка подбора токена, лимиты частоты, таймауты) описана в `docs/server.md`, усиление на хостинге
(systemd, Caddy, брандмауэр) в `docs/hosting.md`.

### Как менять содержимое

- **Новые слова** — массив `RAW` в `src/data/korean/dictionary.ts` (поля `n, k, r, t, s`) и категория в `CAT` в том же файле.
- **Грамматика** — массив `G` в `src/data/korean/grammar.ts`.

Сайт живёт на `korean.meeymirita.ru`; главная `meeymirita.ru` — отдельный проект (`github.com/meeymirita/me`).

После обновления на хостинге **обязательно перезапускать службу сервера** (`systemctl restart progress`): новый столбец базы и новые
возможности работают только на свежем коде сервера.

Сайт — одностраничное приложение, поэтому на хостинге все адреса должны отдавать `index.html`.

### SEO

Каждая открытая страница получает свой заголовок, описание, canonical и Open Graph при переходе (`src/data/seo.ts`, подставляет роутер);
закрытые токеном страницы помечены `noindex`. В `public/`: `sitemap.xml`, `robots.txt`, `manifest.webmanifest`, значки и `og-image.png`
(превью для соцсетей). В `index.html`: метатеги, JSON-LD (WebSite и LearningResource), текст для тех, у кого выключен JavaScript.
Добавил открытую страницу: допиши её в `seo.ts` и `sitemap.xml` (тест `tests/seo.test.mjs` следит, чтобы они совпадали).
Сайт одностраничный (Vue, не SSR), поэтому в конце `npm run build` запускается предварительная отрисовка (`scripts/prerender.mjs`): для каждой
открытой страницы создаётся готовый HTML с метатегами и настоящим содержимым (словарь, грамматика, справочники), который роботы и соцсети видят без JavaScript.
Подтверждение Яндекса лежит в `index.html`. Для работы пререндера Caddy нужен `try_files {path} {path}/index.html /index.html` (`docs/hosting.md`).
