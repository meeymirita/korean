# 우리말 — корейский язык

> **Живой сайт:** https://korean.meeymirita.ru

**우리말** (по-корейски «наш язык», «родной язык») — личная платформа для изучения корейского языка с нуля. Это не набор разрозненных
страниц, а одно спокойное место, где можно учить слова и грамматику, повторять по интервалам, играть в игры на слова, вести заметки с
картинками, следить за прогрессом и временем занятий и ничего не искать по другим сайтам. Платформа выросла из занятий по курсу
서울대 한국어+ 1A и видеокурсу, а материал ведётся вместе с учителем.

## Для чего и для кого

- **Учиться ежедневно по чуть-чуть:** «Сегодня» собирает слова дня, правило и задания, «Повторение» напоминает, что пора освежить, цель дня и серия
  занятий мягко возвращают завтра.
- **Только пройденное:** сайт не забегает вперёд. Уроки и формы, которые ещё не проходили (например, будущее время), в заданиях не появляются.
- **Без звука и без лишнего:** никакой озвучки; упор на чтение, письмо, правила и практику. Вид пастельный и тихий, без рекламы и счётчиков.
- **Своё пространство:** личный кабинет с профилем и обложкой, заметки, галерея картинок, таймер занятий, достижения, сад и коллекция карточек.
- **Открытое и закрытое:** справочники (слова, грамматика, шпаргалка, разговорник, хангыль, алфавит, чтение, примеры, числа) открыты всем, а задания,
  тренажёры, игра, повторение и кабинет работают после входа по токену; для гостей есть временные ссылки, которые ничего не сохраняют.

## Что внутри

- **555 слов** по 12 темам с чтением русскими буквами, переводом и примером, который разбирается по словам и частицам.
- **58 правил грамматики** карточками: формулы, таблицы, примеры, пройденное отмечено.
- **Справочник из 7 вкладок**, тренажёры («найди пару», «напиши перевод»), **игра «Хлебушек» с 20 режимами**, блицем и выживанием.
- **Прогресс:** 40 уровней, серия дней, цель дня, статистика по словам, сад воспоминаний, коллекция карточек, 15 достижений, итоги недели.
- **Поиск по всей платформе** в одном окне (Ctrl/⌘ + K) без переходов, заметки с картинками, свои картинки, таймер занятий.
- **Надёжность:** сервер с базой SQLite, ежедневные копии базы и зашифрованный архив на почту, защита от подбора токена, повторный токен для опасных действий, SEO.

## Техническая часть

**Стек:** Nuxt 4 (отрисовка на сервере), Vue 3, TypeScript, Pinia; сервер NestJS + SQLite (`node:sqlite`); Caddy и systemd на хостинге.

```
frontend/   сайт (Nuxt): src/pages, views, components, stores, data, game; public/
backend/    сервер API (NestJS): база и картинки в backend/data/ (в git не попадает)
tests/      тесты проекта (node --test); у frontend/ и backend/ свои тесты фреймворков
docs/       документация по темам; scripts/ — деплой, копии, утилиты
```

### Запуск

Нужен Node 22.22+ или 24.15+.

```sh
npm ci && npm --prefix frontend ci && npm --prefix backend ci
echo "PROGRESS_TOKEN=$(openssl rand -base64 24)" > backend/.env   # токен для входа
npm run server:dev     # API на 127.0.0.1:3001
npm run dev            # сайт на http://localhost:3000, /api проксируется на сервер
```

Проверки: `npm test` (все тесты), `npm run type-check`, `npm run build`. На каждый push GitHub запускает те же проверки (`.github/workflows/ci.yml`).

### Доступ

Справочники, слова, грамматика, главная и «О платформе» открыты всем. Задания, тренажёры, игра, повторение, магазин и кабинет открываются по токену из `backend/.env`
(рядом с такими разделами в меню замок). Опасные действия (сброс прогресса, загрузка копии, гостевой токен) просят токен ещё раз.
Для гостей есть временные ссылки: гость всё видит, но ничего не сохраняет.

### Данные и прогресс

Слово считается выученным, когда наберёт 5 очков (верный ответ +1, ошибка −1). Прогресс, заметки, картинки и настройки лежат в базе на сервере; сайт показывает результат сразу,
а действия уходят пачкой через секунду, без сети копятся в браузере. Слова и грамматика лежат файлами в `frontend/src/data/korean/` (`dictionary.ts`, `grammar.ts`), подробности в `docs/data.md`.

### SEO

Заголовки, описания и индексация страниц заданы в `frontend/src/data/seo.ts`; `sitemap.xml` и `robots.txt` Nuxt строит сам. Открытые страницы отдаются готовым HTML,
закрытые токеном рисуются только в браузере.

### Выкладка

На сервере одна команда: `bash scripts/deploy.sh` (обновляет код и пакеты, собирает, перезапускает службы, проверяет и при ошибке откатывает). Подробности: `docs/hosting.md`.
Прежняя версия на Vue без сервера отрисовки сохранена в ветке `main_old`.
