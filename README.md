# Хлебушек — корейский язык
## Стек

- Vue 3 (Composition API, `<script setup>`)
- TypeScript
- Vite
- Pinia — хранилище прогресса
- Vue Router

## Запуск

```sh
npm install
npm run dev
```

Сборка и проверка типов:

```sh
npm run build
npm run preview
```

## Доступ по токену

Справочники открыты всем: слова, грамматика, шпаргалка, разговорник, хангыль, алфавит, правила чтения, примеры, числа.
Задания «Сегодня», тренажёры, повторение, игра и «Мой кабинет» открываются после ввода токена (он тот же, что в
`server/.env`). Пока токен не введён, в меню рядом с этими разделами замок, а на их страницах поле для токена.
На каждом устройстве токен вводится один раз; «Выйти» в кабинете → «Настройки» закрывает доступ на этом устройстве.

## Прогресс и сервер

Каждый верный ответ (игра, тренажёры, «Сегодня») даёт очки; слово считается выученным после трёх верных ответов
подряд. Прогресс хранится в браузере, а при желании ещё и на сервере (`server/index.mjs`): один JSON-файл
`server/data/progress.json` и копии по дням в `server/data/backups/` (последние 30).

Быстрый старт сервера (нужен Node, пакеты ставить не надо):

1. Создай файл с паролем (токеном). Пароль придумываешь ты, он защищает запись от посторонних:
   ```sh
   echo "PROGRESS_TOKEN=$(openssl rand -hex 12)" > server/.env
   cat server/.env        # покажет пароль, он понадобится на сайте
   ```
   Или скопируй `server/.env.example` в `server/.env` и впиши свой пароль. Файл `server/.env` в git не попадает.
2. Запусти сервер: `npm run server` (слушает `127.0.0.1:3001`). Чтобы он работал всегда:
   `pm2 start server/index.mjs --name progress`, затем `pm2 save` (если нет pm2: `npm i -g pm2`).
3. Подключи его в Caddy (ниже), затем открой на сайте «Прогресс», вставь тот же пароль в поле «токен сервера» и
   нажми «Подключить».

В разработке `npm run dev` сам проксирует `/api` на этот сервер. На хостинге наружу его выставляет Caddy:

```
example.ru {
    handle /api/* {
        reverse_proxy 127.0.0.1:3001
    }
    handle {
        root * /путь/к/проекту/dist
        try_files {path} /index.html
        file_server
    }
}
```

После правки Caddyfile: `caddy reload`. Если на странице «Прогресс» пишет «неверный токен», пароль в поле не совпадает с
тем, что в `server/.env`; если «сервер недоступен», не запущен сервер или нет блока `handle /api/*` в Caddy.
Свежая версия (по `updated`) побеждает, после каждого ответа изменения уходят на сервер
через секунду-две. Файл `server/data/` не коммитится.

## Как менять содержимое

- **Новые слова** — массив `RAW` в `src/data/korean/dictionary.ts` (поля `n, k, r, t, s`) и категория в `CAT` в том же файле.
- **Грамматика** — массив `G` в `src/data/korean/grammar.ts`.

Сайт живёт на `korean.meeymirita.ru`; главная `meeymirita.ru` — отдельный проект (`github.com/meeymirita/me`).

Сайт — одностраничное приложение, поэтому на хостинге все адреса должны отдавать `index.html`.
