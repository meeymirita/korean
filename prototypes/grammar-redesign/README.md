# Прототипы редизайна /korean/grammar

Три варианта на настоящих карточках из `grammar.ts` (данные выгружены в `data.js`), вне сайта, без сборки.

- `v01-shelf.html`: книжная полка, книга открывается разворотом, листы листаются свайпом и за уголок.
- `v10-miller.html`: колонки как в Finder (раздел, тема, просмотр), стрелки клавиатуры.
- `v15-chat.html`: диалог «Что хочешь сказать?», примеры пузырями речи.

Запуск: `cd prototypes/grammar-redesign && python3 -m http.server 5300`, открыть `http://127.0.0.1:5300/`.
`data.js` собран из `frontend/src/data/korean/grammar.ts` на 2026-11-27 и не обновляется сам.
