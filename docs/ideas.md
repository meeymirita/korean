Это **предложения, а не решения**: по `CLAUDE.md` (правило 16) новая библиотека, крупный интерактив или переделка начинается с коротких вариантов и слова владельца «давай».

## 1. Учёба: что даст больше всего пользы

### 1.1 Настоящее интервальное повторение (SM-2 / FSRS-lite) — **главная идея**

**Сейчас:** интервал зависит только от `streak` слова: 0 → сразу, 1 → 1 день, 2 → 3, 3 → 7, 4 → 14, ≥5 → 30 (`docs/progress.md`, `data/review.ts`). Не учитывается, насколько слово «тяжёлое» именно для тебя и как быстро ты отвечал.
**Что сделать:**
- Хранить для каждого слова «лёгкость» (`ease`, старт 2.5) и дату следующего повторения; «Помню» растит интервал в `ease` раз, «Не помню» сбрасывает и снижает `ease`.
- Добавить третью кнопку в раунде «Повторения»: «Трудно» (клавиша 3) между «Помню» и «Не помню» — интервал растёт слабее.
- Показывать в «Обзоре» прогноз: «завтра к повторению N слов, на неделе M» (график на существующих `components/charts`).
**Где:** `frontend/src/data/review.ts` (`intervalDays`, `pickSession`), `stores/progress.ts`, `backend/src/progress/progress.service.ts`; миграция только добавлением столбцов/полей (правило про Prisma). Старый `streak` оставить как запасной для слов без истории.
**Риск/цена:** средняя; сервер и сайт должны считать одинаково (как `KNOWN_STREAK`, менять в обоих местах); нужен тест на сходимость интервалов.

### 1.2 Предложения и грамматика тоже в расписании повторения

Слова повторяются по графику, а карточки грамматики — нет (есть только «Слабые правила» в обзоре). Завести для пройденных (`ok`) карточек тот же график: «пора освежить правило» → короткая серия «Потренировать правило» (`RuleView`, уже есть). Это закрывает дыру «выучил правило неделю назад и забыл».

### 1.3 «Рассказ из моих ошибок» (отложено владельцем 2026-11-09, `docs/trainers/mistakes.md`)

Причина откладывания: нет предложений для каждого слова. Обходной путь без новых слов: брать предложения из `STUDY_TRANSLATIONS`/`game/ptext-pool.ts` (~1170 предложений), в которых встречается слово с ошибкой; если предложения нет — слово просто остаётся в обычной серии. Так фича не требует новых данных и не выключается молча.

### 1.4 Подготовка к субботнему созвону с учителем

Раз в неделю нужен «лист к уроку»: что прошли с прошлой субботы, что в этом списке слабое, что хочется спросить.
- Страница или блок в «Сегодня» по пятницам: слабые слова недели + правила с низкой точностью + пустое поле «Вопросы учителю» (хранится как заметка).
- Выгрузка одним PDF (механика PDF-отчёта в Telegram уже есть: `digest`, недельный отчёт) — можно отправлять в Telegram в пятницу вечером.

### 1.5 Режим «Диктант без звука»: письмо по памяти

Звука нет, но есть полезный аналог: показать русский перевод и чтение русскими буквами, ввести корейское слово/фразу (есть `KeyboardView` и `TypingQuiz`). Недостающее — **свободное написание фразы по теме** с проверкой по «допустимым ответам» (как в экзамене `ACCEPT` и `altOrders`). Начать с коротких фраз из «Разговорных формул» (`phr`), где ответ однозначен.

### 1.6 Недельная цель и «план недели» — **сделано 2026-11-13** (кольцо в «Сегодня», цель в «Настройках», строка в отчёте; «1 часть экзамена» в цель не вошла)

Цель дня есть, недельной нет. Простая версия: «в эту неделю: 5 дней занятий, 100 верных ответов, 1 экзаменационная часть», прогресс-кольцо в «Сегодня», итог в воскресном отчёте. Данные уже собираются (`week` в кабинете, отчёт).

### 1.7 Карточки «слово в контексте» из реальных предложений

В «Повторении» у слов, у которых есть пример (`examples` и разбор по частицам), показывать пример на обороте. Само по себе помогает запоминанию больше, чем пара «слово — перевод». Данные есть (разбор `parse.ts`), нужна только вёрстка оборота карточки.

### 3.5 Расписание занятий и напоминания «по привычке»
