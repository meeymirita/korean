## 1. Учёба: что даст больше всего пользы

### 1.1 Настоящее интервальное повторение (SM-2 / FSRS-lite) — **главная идея**

**Сейчас:** интервал зависит только от `streak` слова: 0 → сразу, 1 → 1 день, 2 → 3, 3 → 7, 4 → 14, ≥5 → 30 (`docs/progress.md`, `data/review.ts`). Не учитывается, насколько слово «тяжёлое» именно для тебя и как быстро ты отвечал.
**Что сделать:**
- Хранить для каждого слова «лёгкость» (`ease`, старт 2.5) и дату следующего повторения; «Помню» растит интервал в `ease` раз, «Не помню» сбрасывает и снижает `ease`.
- Добавить третью кнопку в раунде «Повторения»: «Трудно» (клавиша 3) между «Помню» и «Не помню» — интервал растёт слабее.
- Показывать в «Обзоре» прогноз: «завтра к повторению N слов, на неделе M» (график на существующих `components/charts`).
**Где:** `frontend/src/data/review.ts` (`intervalDays`, `pickSession`), `stores/progress.ts`, `backend/src/progress/progress.service.ts`; миграция только добавлением столбцов/полей (правило про Prisma). Старый `streak` оставить как запасной для слов без истории.
**Риск/цена:** средняя; сервер и сайт должны считать одинаково (как `KNOWN_STREAK`, менять в обоих местах); нужен тест на сходимость интервалов.

### 1.2 Предложения и грамматика тоже в расписании повторения

Слова повторяются по графику, а карточки грамматики — нет (есть только «Слабые правила» в обзоре). Завести для пройденных (`ok`) карточек тот же график: «пора освежить правило» → короткая серия «Потренировать правило» (`RuleView`, уже есть). Это закрывает дыру «выучил правило неделю назад и забыл».

### 1.3 «Рассказ из моих ошибок» (отложено владельцем 2026-11-09, `docs/trainers/mistakes.md`)

Причина откладывания: нет предложений для каждого слова. Обходной путь без новых слов: брать предложения из `STUDY_TRANSLATIONS`/`game/ptext-pool.ts` (~2600 предложений (на 2026-11-17)), в которых встречается слово с ошибкой; если предложения нет — слово просто остаётся в обычной серии. Так фича не требует новых данных и не выключается молча.

### 1.4 Подготовка к субботнему созвону с учителем (есть страница «Что я уже знаю», `/korean/know`; пятничного листа с вопросами учителю и PDF нет)

Раз в неделю нужен «лист к уроку»: что прошли с прошлой субботы, что в этом списке слабое, что хочется спросить.
- Страница или блок в «Сегодня» по пятницам: слабые слова недели + правила с низкой точностью + пустое поле «Вопросы учителю» (хранится как заметка).
- Выгрузка одним PDF (механика PDF-отчёта в Telegram уже есть: `digest`, недельный отчёт) — можно отправлять в Telegram в пятницу вечером.

### 1.5 Режим «Диктант без звука»: письмо по памяти

Звука нет, но есть полезный аналог: показать русский перевод и чтение русскими буквами, ввести корейское слово/фразу (есть `KeyboardView` и `TypingQuiz`). Недостающее — **свободное написание фразы по теме** с проверкой по «допустимым ответам» (как в экзамене `ACCEPT` и `altOrders`). Начать с коротких фраз из «Разговорных формул» (`phr`), где ответ однозначен.

### 1.7 Карточки «слово в контексте» из реальных предложений

В «Повторении» у слов, у которых есть пример (`examples` и разбор по частицам), показывать пример на обороте. Само по себе помогает запоминанию больше, чем пара «слово — перевод». Данные есть (разбор `parse.ts`), нужна только вёрстка оборота карточки.

## 3. Инструменты для самого владельца

### 3.1 Умный поиск «где я это видел»

Поиск (Ctrl/⌘+K) уже находит слова и страницы. Добавить: из результата слова видеть **все предложения, где оно встречалось**, карточки грамматики, где оно в примерах, и свои заметки с этим словом. Данные уже есть в `STUDY_TRANSLATIONS` и заметках; индекс Meilisearch можно расширить типом документа.

### 3.2 Экспорт ошибок недели

Слова уже скачиваются (CSV в «Настройках»). Не хватает кнопки «Скачать ошибки недели» (отдать учителю, распечатать). Нужен эндпоинт сервера и кнопка в «Настройках».

### 3.3 Теги и свои списки слов

Слова приходят во «Входящие» от Claude по токену (таблица `new_words`, страница «Слова» → «API»), но сгруппировать их по уроку или теме до переноса в словарь нельзя. Дать теги «урок 12», «от учителя», «из сериала» + фильтр на странице «Слова». Теги уже есть в бэкенде (`backend/src/tags.ts`), нужно выяснить, подходят ли они под слова.

### 3.4 Заметки: связи

Добавить в заметки ссылки на слово или карточку правила в тексте (`[[слово]]` открывает окно слова). Это превращает заметки из архива в живую «тетрадь».

### 3.5 Расписание занятий и напоминания «по привычке»

Напоминания в Telegram есть. Добавить «умное время»: бот смотрит, в какие часы владелец обычно занимается (по журналу), и присылает напоминание за 10 минут до привычного времени, а если уже занимался сегодня, молчит. Данные есть в журнале ответов и таймере.

## 8. Ещё идеи (вторая порция, 2026-11-13)

### Учёба
- **«Слабое место дня»**: в «Сегодня» одна карточка «сегодня потренируй это» (самое проваленное правило или слово за неделю) с кнопкой в серию на 5 заданий.
- **Подтверждение «знаю на самом деле»**: слово, которое десять раз подряд отвечено верно, можно пометить «знаю» и убрать из повторения совсем (с возможностью вернуть).
- **Режим «наоборот»** в повторении: сначала русский, потом вспомнить корейское (в играх `rev` есть, в карточках повторения нет).
- **Мини-диалоги по темам**: короткие сценки (магазин, кафе, знакомство) из уже пройденных слов и частиц, ответы выбираются плитками (на базе `dlg` и `EXCHANGES`).
- **Чтение коротких текстов**: «рассказы» из 4–6 предложений с разбором по словам при нажатии (механика разбора `parse.ts` уже есть) и вопросами на понимание.
- **Тренажёр счётных слов с картинками**: предмет на картинке, нужно выбрать счётное слово и число (картинки грамматики уже лежат на Яндекс.Диске).
- **Таблица спряжения «как в тетради»**: пустая таблица форм глагола, которую заполняешь вводом; проверка по `CONJUGATIONS`.
- **Дневник ошибок по темам**: список «что чаще путаю» с примерами и ссылкой на правило, обновляется сам из журнала.

### Мотивация
- **Заморозка серии**: один раз в неделю можно пропустить день без потери серии (за монетки из магазина).
- **Итог года / месяца**: красивая картинка «за месяц: слов выучено, часов занятий, лучший день» для сохранения и отправки в Telegram.
- **Цели на уровень**: «до следующего уровня осталось N очков» на видном месте в «Сегодня».
- **Редкие стикеры и события**: на уровнях 50, 75, 100 особая карточка в саду и сообщение в Telegram.
- **История занятий в виде ленты**: «сегодня 14:20 · 18 верных · блиц 60 с» одной прокручиваемой лентой.

### Словарь `/dict`
- **«Слово дня»** на странице словаря и в Telegram (из уровня 1–2 по списку института, но только если слово уже в `STUDY`).
- **Сохранить слово в «мои»** одной кнопкой: добавляется в «Новые слова» для обсуждения, без ручного ввода.
- **Фильтры подборок**: по части речи, уровню, длине, «есть в моём словаре / нет».
