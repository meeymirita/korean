# Telegram: уведомления в группу с темами

Все уведомления платформы приходят в Telegram-группу с темами (форум), каждый вид в свою тему, с баннером и оформлением. Токены и ключи в документ не вносятся (только имена переменных). Код: `backend/src/notify/`, шаблоны `backend/src/mail/templates.ts`.

## 1. Что и куда приходит

| Тема | `topic` | Что приходит |
|---|---|---|
| Вход (3) | `login` | код входа и подтверждение включения двухфакторной защиты |
| Напоминания (9) | `remind` | «Пора заниматься» (`ReminderBlock`) |
| Подборка слов (11) | `digest` | слова и предложения на повторение (`DigestBlock`) |
| Созвон (13) | `lesson` | «Сегодня созвон» (`LessonBlock`) |
| Копии (15) | `backup` | отчёты о резервных копиях, проверка отправки |
| Тревоги (17) | `alert` | ночная копия не удалась или давно не делалась, копия не легла на Диск, архив слишком большой |

Номера тем в скобках (из `.env`). Каждое письмо в `templates.ts` отдаёт и версию для Telegram (поле `tg`) и `topic`.

**Порядок отправки (`NotifyService.send`).** Задана группа: только в тему группы (личный чат бота не используется вовсе, даже для кода входа; в группе должны быть только владелец и бот). Группа не задана: в личный чат `TELEGRAM_CHAT_ID`. Нет номера темы для этого вида или Telegram не отвечает: письмо на почту, если настроены `SMTP_*` и адрес. Письма с вложением (архив при запасной почте) идут только по почте. Двухфакторная защита с Telegram не просит адрес почты: сохраняется метка `telegram`.

## 2. Настройка

Корневой `.env` на сервере (`/var/sites/korean/.env`), в `docker-compose.yml` переменные проброшены в `backend`; после правки `docker compose up -d`. Образец: `.env.example`.

| Переменная | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота `@yunaYrima_bot` (из @BotFather, перевыпуск `/revoke`) |
| `TELEGRAM_GROUP_ID` | число `-100…`, группа с темами |
| `TELEGRAM_TOPIC_LOGIN`, `_REMIND`, `_DIGEST`, `_LESSON`, `_BACKUP`, `_ALERT` | номера тем группы |
| `TELEGRAM_CHAT_ID` | личный чат владельца; нужен только без группы |
| `TELEGRAM_BANNER_BASE` | откуда Telegram берёт баннеры, по умолчанию `https://korean.meeymirita.ru` |
| `TELEGRAM_CUSTOM_EMOJI` | `0` выключает анимированные эмодзи |
| `TELEGRAM_DUMP_FILE` | для тестов: вместо отправки пишет JSON в файл |

Права бота в группе (администратор): «Управление темами», «Удаление сообщений» (очистка), «Закрепление сообщений» (General).

## 3. Оформление

- Шапка `<сердечко> 우리말 <сердечко>`, линия из чёрточек, заголовок, текст, заметка, подпись (`tgCard`). Сердечко своего цвета у темы (`TG_HEART`): вход 💙, напоминания 🩷, подборка 💜, созвон 🩵, копии 🤍, тревоги ❤️.
- **Анимированные эмодзи.** Bot API разрешает `<tg-emoji emoji-id>` и иконку кнопки (`icon_custom_emoji_id`), если у владельца бота есть Telegram Premium. Номера в `TG_CUSTOM_EMOJI` (набор `lolityanmur1_by_fStikBot`): белая бабочка у «Копий», фиолетовая у «Подборки слов», котик у «Напоминаний». Внутри тега обычное сердечко темы: его видит тот, у кого нет Premium. Telegram не принял эмодзи: `tgRaw` повторяет запрос без них (`stripCustom`).
- **Кнопки** (под сообщением темы и кнопки-переходы в General, `tgButtonFor`): все красные (`style: danger`, решение владельца; Telegram знает только синюю, зелёную и красную), перед текстом анимированная иконка темы, а если её нет, сердечко темы.
- **Подборка слов:** «Проверь себя», слово жирным, перевод под спойлером, без значков перед словами.
- Цитаты (blockquote) не используются: цвет их полоски менять нельзя, заметки идут строкой с сердечком темы.
- Код входа в `<code>`: копируется нажатием.

## 4. Баннеры

Файлы 1280×640 в `frontend/public/tg/`: `tg-login`, `tg-remind`, `tg-digest`, `tg-lesson`, `tg-backup`, `tg-alert` (по теме) и `tg-banner.png` (по умолчанию для сообщения в General). Публикуются вместе с сайтом по адресу `/tg/<имя>.png?v=<BANNER_VERSION>`, сообщение уходит фото с подписью (подпись до 1000 знаков, длиннее: баннер отдельно, потом текст). Баннера нет на сайте или Telegram его не скачал: обычное текстовое сообщение.

**Заменил баннеры: увеличь `BANNER_VERSION` в `notify.service.ts`**, иначе Telegram какое-то время будет показывать старые (он запоминает картинку по адресу).

## 5. Вкладка «Telegram» в кабинете (`/korean/cabinet?tab=telegram`, только владелец)

- У каждой темы: метка «подключена», кнопка **«Пример сообщения»** (`POST /api/notify/sample`: настоящий шаблон с выдуманными данными, `sampleMail`), поле «Свой текст» (`/api/notify/topic`) и **«Очистить тему»**. Всё уходит строго в эту тему, не на почту и не в личный чат.
- **«Очистить»** (`POST /api/notify/clear`) идёт только с повторным вводом токена (`ConfirmService.require`). Тема: удаляются сообщения, которые отправил сайт (номера в `meta` под ключом `tg:sent:<тема>`, последние 500; записи владельца, например закреплённое описание, остаются). «Очистить все темы»: удаляется вообще всё во всех темах и в General (перебором номеров от 1 до последнего), темы остаются.
- **Сообщение в General** (`TelegramGuide.vue`, `GET/POST /api/notify/guide`, `GET /api/notify/guide/banner`): редактор целого закреплённого сообщения (текст с тегами Telegram b, i, u, s, code, a; свой баннер, который загружается прямо в Telegram, у нас хранится только `file_id` в `meta.tg:guide`; предпросмотр). Под сообщением сами идут кнопки-переходы по темам (`https://t.me/c/<группа без -100>/<номер темы>`). «Сохранить и отправить» правит уже отправленное сообщение на месте, иначе отправляет новое и закрепляет; «Отправить заново» удаляет старое. Пока свой баннер не загружен, берётся `tg-banner.png`. С баннером текст не длиннее 1024 знаков. После полной очистки сообщение отправляется заново этой же кнопкой.

## 6. Как узнать номера (темы, эмодзи)

Бот читает сообщения группы через `getUpdates` (хранится 24 часа). Команды короткие, чтобы не рвались при вставке; токен нигде не печатается:
```
T=$(grep ^TELEGRAM_BOT_TOKEN /var/sites/korean/.env | cut -d= -f2-)
curl -s "https://api.telegram.org/bot$T/getUpdates" -o /tmp/u.json
grep -o '"custom_emoji_id":"[0-9]*"\|"message_thread_id":[0-9]*' /tmp/u.json | tail -30
rm /tmp/u.json
```
- **Номер темы:** написать в тему слово; `message_thread_id` рядом. Название темы в `getUpdates` устаревает после переименования, ориентируйся на то, где написал.
- **Номер анимированного эмодзи:** написать в группу сообщение с этим эмодзи; идёт строкой `custom_emoji_id`. Набор по номерам: `getCustomEmojiStickers` (поле `set_name`).

## 7. Поломки

| Симптом | Что смотреть |
|---|---|
| уведомление не пришло | в кабинете «Telegram»: «Пример сообщения» в эту тему; `getMe` (токен), номер темы в `.env`, права бота; сообщение уйдёт письмом, если настроена почта |
| пришло без баннера | баннер ещё не выложен на сайт (деплой) или файл не открывается по `/tg/<имя>.png`; в журнале `docker compose logs backend` строка «баннер не ушёл» |
| пришёл старый баннер | кэш Telegram: увеличить `BANNER_VERSION` |
| вместо анимированного эмодзи обычное сердечко | нет Premium у владельца бота (или номер не из его набора); `TELEGRAM_CUSTOM_EMOJI=0` выключает совсем |
| «Очистить» отвечает ошибкой | неверный токен (403), нет права «Удаление сообщений» у бота |
| сообщение в General не закрепилось | боту нужно право «Закрепление сообщений» |
