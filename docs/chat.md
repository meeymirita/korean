# Помощник: чат с вопросами по корейскому (`/korean/chat`)

Пишешь вопрос, получаешь ответ по-русски. Работает через **бесплатные модели OpenRouter** (OpenAI-совместимый `POST /chat/completions`; Gemini не подошёл из-за ошибки доступа).

## Доступ
Только владелец: сервер `@Owner()` (гость 403, без токена 401), раздел с `owner: true` в `sections.ts` скрыт у гостя, страница закрыта токеном, `noindex`.
Ключ только в `backend/.env`, на сайт не попадает. **Никогда не вставлять ключ в чат и репозиторий** (выделение строки с ключом в редакторе тоже отправляет её в переписку): ключ, попавший в чат, перевыпустить.
Ключу в OpenRouter стоит поставить маленький лимит (Limit = 1): используем только бесплатные модели.

## Настройки (`backend/.env`, образец `backend/.env.example`)
| Переменная | По умолчанию | Что делает |
|---|---|---|
| `OPENROUTER_API_KEY` | пусто | ключ с openrouter.ai/keys; без него `POST /api/chat` отвечает 503, страница пишет «не подключён» |
| `CHAT_MODEL` | `openrouter/free` | модель; сейчас `nvidia/nemotron-3-ultra-550b-a55b:free` (бесплатные оканчиваются на `:free`) |
| `CHAT_DAILY_LIMIT` | 40 | вопросов в сутки (по UTC); у бесплатного тарифа OpenRouter 20 в минуту и 50 в день |
| `CHAT_BASE` | `https://openrouter.ai/api/v1` | адрес API (в тестах подменяется) |
После изменения `.env` перезапусти службу (`bash scripts/deploy.sh --force` или `systemctl restart progress`).

## Как устроено
- **Сервер** `backend/src/chat/`: `chat.service.ts` проверяет переписку (роли `user`/`assistant`, до 2000 знаков, в модель уходят последние 12), считает суточный лимит (в памяти),
  при пустом ответе повторяет один раз, ошибки вопрос не списывают (таймаут 40 с). `chat.controller.ts`: `GET /api/chat` → `{configured, model, limit, left}`, `POST /api/chat` → `{reply, left}`
  (ошибки: 400, 429, 502, 503). Переписку сервер не хранит.
- **Сайт:** `src/lib/chat.ts` (запросы, понятные ошибки, безопасный показ ответа без HTML, `koreanParts`), `src/views/korean/ChatView.vue` (переписка в `sessionStorage`, счётчик «осталось N из 40»,
  Enter отправляет, Shift+Enter новая строка). Кнопка **«Разобрать»** под ответом прогоняет корейские фразы через `SentenceBreakdown` (чтение и перевод слов берёт из словаря сайта).
- **Инструкция модели** (`prompt.ts`): ответы по-русски и коротко; не заходить дальше пройденного (без будущего времени, «хочу», «могу», вежливых форм); примеры из словаря ученика;
  **чтение не писать** (модель ошибалась; его считает сайт); каждая корейская фраза отдельной строкой; пол ученика неизвестен; не выдумывать слова и правила; только про корейский.
  Списки пройденных тем и слов подставляются из `curriculum.ts`: после изменения словаря или отметки новых уроков пройденными запусти `node scripts/chat-curriculum.mjs` и закоммить результат (иначе упадёт `tests/chat-prompt.test.mjs`).

## Что известно о качестве
`openrouter/free` (автовыбор) ошибался в частицах и чтении, не годится. `nvidia/nemotron-3-ultra-550b-a55b:free` на проверочном наборе ответила верно, но бесплатная модель всё равно может ошибаться
в редких словах: ответам не верить без сверки с «Грамматикой» и учителем (написано и на странице). Бесплатные модели могут хранить тексты вопросов: «личного не пиши».
