# Голосовой собеседник

Код написан 2026-11-16 в ветке **`feature/voice`** (в `main` не слит, на сайт не выложен). Идея владельца: кнопка сверху и окно как у музыкального плеера (`docs/music.md`), внутри микрофон и запись разговора, без шара (orb). Говоришь по-корейски, собеседник отвечает голосом; текст разговора сохраняется.

## Решения владельца (2026-11-16)

- Голос с микрофоном отменяет «звука нет» для этой функции (записано в `CLAUDE.md`).
- **20 минут в сутки** (`VOICE_DAILY_MINUTES=20`, поднято с 10 по слову владельца 2026-11-16: за 9 минут вышло около $0.45) и не больше 10 минут за один разговор; в окне видно «осталось N из 20 мин» и примерную цену.
- Orb не нужен: пока просто кнопка с микрофоном. Картинки владелец сгенерирует сам (сейчас значки рисует код, `components/voice/*.vue`, SVG).
- Разговор **остаётся включённым при закрытом окне**: сверху мини-плашка (таймер, микрофон, «закончить»), как мини-плеер у музыки.
- **Расшифровки хранятся полностью** в базе (звук не хранится): вкладка «История», удаление по кнопке.

## Как это работает

```
Браузер (микрофон, звук ответа) ──WebRTC──► OpenAI Realtime API
        │                                          ▲
        └─ 1. просит временный ключ ► наш сервер ──┘ настоящий ключ только в .env сервера
```

1. `POST /api/voice/sessions` (только владелец): сервер проверяет остаток минут, просит у OpenAI временный ключ (`POST /v1/realtime/client_secrets`, живёт 2 минуты, в запросе модель, голос, инструкция преподавателя, расшифровка речи, заголовок `OpenAI-Safety-Identifier`), заводит запись разговора и отдаёт браузеру ключ и номер.
2. Браузер соединяется напрямую с OpenAI: микрофон, канал `oai-events`, SDP на `POST /v1/realtime/calls`. Звук мимо нашего сервера.
3. События канала `conversation.item.input_audio_transcription.completed` (речь ученика) и `response.output_audio_transcript.done` (ответ) сайт отправляет на `POST /api/voice/sessions/:id/messages`.
4. Конец: `POST /api/voice/sessions/:id/end`. **Секунды считает сервер по своим часам** (не больше предела), недосчитанные (вкладку закрыли) тоже засчитываются до предела.
5. Сам разговор заканчивается при выходе времени или после 60 секунд полной тишины.

## Настройки (`.env` сервера)

| Переменная | По умолчанию | Что |
|---|---|---|
| `OPENAI_API_KEY` | пусто | ключ с platform.openai.com; без него окно пишет «не подключён» (503) |
| `VOICE_MODEL` | `gpt-realtime-2.1-mini` | модель (выбор владельца, 2026-11-16: только эта) |
| `VOICE_VOICE` | `marin` | голос |
| `VOICE_DAILY_MINUTES` | 20 | минут в сутки (по `VOICE_TZ`, по умолчанию `Asia/Novosibirsk`) |
| `VOICE_MAX_SESSION_MIN` | 10 | предел одного разговора |
| `VOICE_COST_PER_MIN` | 0.05 | **примерная** цена минуты в долларах, только для подсказки на экране; настоящий расход смотреть в кабинете OpenAI |

После правки `.env`: `docker compose up -d backend`.

## Что нужно от владельца

1. **Ключ OpenAI в `.env` сервера** (`OPENAI_API_KEY=...`). Мне ключ не присылать, в чат и репозиторий не вставлять (правило 17). Перевыпустить, если попал в чат.
2. **Страница лимитов OpenAI сообщила «Limit not enforced»**: лимит $100 в аккаунте только предупреждает, запросы **не останавливает**. Реальная страховка это наши 20 минут в сутки; в кабинете OpenAI оставить оповещения.
3. **Проверить настоящую цену минуты** на странице цен OpenAI и поправить `VOICE_COST_PER_MIN` (сейчас 0.05 — прикидка; у `gpt-realtime-2` аудио $32 / $64 за 1 млн токенов, у mini дешевле, точные цифры источники давали разные).
4. **Руками в боевой Caddy** (его нет в git): в заголовке `Permissions-Policy` заменить `microphone=()` на `microphone=(self)` (`docs/hosting.md`, блок Caddy), перезагрузить Caddy.
5. **Картинки значков** (микрофон, запись, стоп, закрыть), если нужны свои: положить в `frontend/src/assets/voice/` (webp, как набор плеера) и сказать, подключу вместо SVG.
6. Слить ветку `feature/voice` в `main` (или сказать мне), когда решишь выкладывать: пуш в `main` сам запустит деплой. Миграция применится сама.
7. Проверить вживую: микрофон на ноутбуке, телефоне и iPad (Safari), качество корейской речи, расход.

## Что не проверено

Настоящий разговор с OpenAI (нужны ключ и баланс), микрофон в браузерах, iPad и телефон, Caddy на боевом сервере. Серверный тест `tests/voice-server.test.mjs` я локально не гонял (нет базы), его запустит CI. Названия событий расшифровки взяты по документации OpenAI GA (`response.output_audio_transcript`), у `conversation.item.input_audio_transcription.completed` страница документации имя не назвала, оно известно по общей схеме Realtime: если в живом разговоре реплики ученика не появятся в окне, смотреть именно его.

## Новая сессия: что делать по порядку (напоминания)

1. `git fetch && git checkout feature/voice && git pull`; прочитать этот файл и `docs/music.md` (образец).
2. Узнать у владельца: ключ положен? Caddy поправлен? Что показал первый настоящий разговор (реплики в окне есть? голос слышно? корейский верный?).
3. Если реплики ученика не сохраняются: открыть консоль браузера, посмотреть реальные имена событий канала `oai-events` и поправить `lineFromEvent` в `stores/voice.ts` (и тест `voice-panel.spec.ts`).
4. Прогнать по одному: `cd backend && npx vitest run test/voice-util.spec.ts`; `cd frontend && npx vitest run test/voice-panel.spec.ts --maxWorkers=1`; `node --test --test-concurrency=1 tests/voice-server.test.mjs` (нужна база, иначе смотреть CI), потом `npm run type-check` и `npm run lint`.
5. Дорожка улучшений (только по слову владельца): кнопка «Разобрать» у корейских фраз в истории (как в чате, `SentenceBreakdown`); свои значки вместо SVG; подпись «Слабые места» из ответов собеседника; режимы разговора («представиться», «в кафе») из пройденного; показывать ошибки отдельным цветом; удаление всех разговоров старше N дней; запись о новой возможности в «О платформе» (`about.ts`, скриншот) и шторку «Что здесь есть» (`guide.ts`).
6. После слова «слей»: PR или слияние в `main`, потом `gh run list --limit 4` (деплой автоматический), напомнить про `.env` и Caddy.
7. `docs/ideas.md` и `plan-and-fixes/plan-new.md` (на Mac): внести пункт «голосовой собеседник» и отметить статус.
