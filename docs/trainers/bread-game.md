# «Хлебушек»: игра на 24 режима (`/game/home?game=<id>`)

**Что это.** Встроенная игра в виде одного движка с 24 режимами (слово → перевод, формы, частицы, собери предложение, диалог, хангыль-блиц и так далее), блицем на 60 секунд и режимом «на выживание». Уровень, очки и ответы общие с сайтом.

**Список режимов, оверлеев и рекордов не дублируется здесь:** он в `docs/games-catalog.md` (таблица режимов) и `docs/game.md` (подробности, «Собери предложение», группы каталога). Этот файл только про то, где что лежит и как не сломать.

**Файлы.**
- `src/game/engine.ts` (~1100 строк): весь движок без типов (`@ts-nocheck`), чистый DOM без Vue: `initGame()`, генераторы `gen…`, `MODES`, `MODE_HELP`, `GEN`, `CATS`, `S` (состояние и рекорды).
- `src/game/markup.html`: разметка (подключается через `v-html`); стили `game.css` (все правила с префиксом `.game`), `redesign.css`, `shell.css`.
- `src/game/words.ts`: **свои** слова игры (`D`: слова, формы глаголов, банки частиц `D.PB`), это не тот же массив, что общий словарь `data/korean/words.ts` (в нём `D` другого вида).
- `src/game/build.ts`: генератор предложений для режима «Собери предложение» (`makeBuild()`, три уровня `LIMITS`); `src/game/dialogs.ts`: `EXCHANGES` для режима `dlg`; `src/game/icons.ts`: иконки режимов.
- `views/GameHomeView.vue`: страница `/game/home`: каталог игр слева, выбранная игра справа (`?game=<id>`), хуки `record`, `state`, `cats` для движка, общая оболочка для тренажёров из `TOOLS`.
  У любой открытой игры (тренажёра или режима движка) наверху одна строка `.gh-back`: «← К списку игр», название игры на белой плашке (`.gh-name`) и кнопки страницы справа (☰ список игр, ⌕ поиск, ☾ тема, кабинет): компонент `components/korean/GameTools.vue`. Шапка каталога (`header.gx-top`, с Юной) рисуется только у каталога. Кнопки режимов игры движка остаются внутри разметки (`.gh-modesrow`), ссылки «назад» в разметке нет. Заголовок «Игры на слова» только для читалок экрана (`.gx-sr`).
- `data/games.ts`: каталог (группы, иконки, описания, `TOOL_IDS`); `data/guide.ts`: те же описания для пользователя (шторка «Что здесь есть»).

**Состояние и хранение.** Статистика игры в `localStorage['hleb_game_v1']` (настройки, статистика, цель дня, слабые слова, рекорды по режимам `S.all.byMode[id]`, `bestBlitz`, `bestSurv`). Уровень, очки и ответы идут в общий прогресс сайта через хук `record` страницы.

**Прогресс и награды.** Ответы пишутся в общий прогресс; **предметы магазина в игре не подключены** (`docs/shop.md`), монеток за серию нет.

**Тесты.** `tests/grammar-data.test.mjs` (у каждого `id` из `MODES` есть `MODE_HELP`), `tests/games-catalog.test.mjs`, `tests/build.test.mjs`, `tests/time-topic.test.mjs`, `frontend/test/game.spec.ts` (каждый режим через настоящий DOM: варианты не повторяются, верный один).

**Как расширять.** Новый режим: `docs/game.md`, раздел «Группы игр в каталоге» (генератор, `MODES`, `MODE_HELP`, `GEN`, список микса, `MODE_ICON`, карточка в `games.ts`, шторка `guide.ts`, группа слов `D.<буква>`, `CATS`/`W`, галочка в `SettingsTab.vue`).

**Подводные камни.** Движок императивный и с общим состоянием `S`: правка одного режима может задеть микс и блиц. Код игры работает и на сервере (Nuxt SSR): инициализация только после монтирования.
