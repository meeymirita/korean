# Собери по слогам (`syllables`)

**Что это.** По русскому переводу собрать корейское слово из плиток-слогов. Плиток на 1–2 больше, чем нужно.

**Где открыть.** `/game/home?game=syllables`. Только по токену.

**Файлы.**
- `views/korean/SyllablesView.vue`: **свой экран, не `TaskSession`**; плитки и слоты на `vuedraggable` (перетаскивание или нажатие), анимации из `lib/fx`.
- `data/korean/syllables.ts`: `syllableTasks(n, weak, level)`, `syllableTask(word)`, `isCorrect`, `SYLLABLE_WORDS`, `SYLLABLE_LEVELS`.
- Использует: `data/mistakes.ts` (`mistakeWords`: слабые слова идут первыми), `words.ts` (`D`), `tasks.ts` (`shuffle`, `short`).

**Уровни** (чипы над заданием, `SYLLABLE_LEVELS`, по аналогии с «Собери предложение»): «Любой» (слова из 2–4 слогов вперемешку), «Простой» (2 слога, 308 слов), «Средний» (3 слога, 108), «Сложный» (4 слога, 40), «Фраза» (два слова подряд из `TRANSLATIONS`, 4–6 слогов, например «학교에 가요»: слоги плиток идут подряд без пробела, верный ответ показывается с пробелом; такие фразы в общий прогресс слов не идут, номер от 16000). Выбор в `usePersisted('syl_level')`, смена уровня собирает новую серию.

**Как собирается набор.** Слова из 2–4 слогов хангылем без пробелов и знаков (`/^[가-힣]{2,4}$/`), отфильтрованные по уровню (`syllableTasks(n, weak, level)`). Серия 10 заданий (`ROUND`); слова с ошибками (своего уровня) первыми, потом случайные. Лишние плитки берутся из слогов других слов: одна, а для слов из 3 и более слогов две.

**Как отвечает игрок.** Нажатием плитка попадает в следующий слот; плитку в слоте можно убрать нажатием или перетащить на другое место. Как только слоты заполнены, ответ проверяется сам (`watch(picked)`): верно или неверно, без кнопки «проверить». Перетаскивание не может дать лишних или повторных плиток (проверка в том же `watch`). Показано чтение слова как подсказка; галочка «показывать чтение» (`syl_reading`) выключает подсказку.

**Состояние и хранение.** Только уровень (`syl_level`, sessionStorage); серия собирается заново при открытии, смене уровня и «Ещё раз».

**Прогресс и награды.** `progress.record({ word, ok, source: 'trainer', mode: 'syllables' })` на каждое слово. **Монеток за серию нет** (нет `roundDone`), **предметы магазина не работают** (см. `CLAUDE.md`, «Что осталось»), отметки «как прошло» нет.

**Тесты.** `tests/syllables.test.mjs`.

**Как расширять.** Чтобы дать монетки и предметы магазина, проще переписать на `TaskSession`, чем дублировать их здесь. Размер серии `ROUND` в `SyllablesView.vue`.

**Подводные камни.** Корейская раскладка здесь не нужна, это не печать. Слог для ответа определяется точным совпадением собранной строки (`assembled(picked) === word.k`).
