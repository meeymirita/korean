# Мои ошибки (`/korean/mistakes`)

**Что это.** Таблица слов, в которых были ошибки, и тренировка только по ним.

**Где открыть.** `/korean/mistakes` (не `?game=`). Только по токену. Страница служебная, в `CLAUDE.md` указана среди служебных.

**Файлы.**
- `views/korean/MistakesView.vue`: кнопка «Потренировать эти слова» / «Другой набор», `TaskSession` (`source="review"`, `mode="mistakes"`), таблица (первые 40, «Показать все N»), ссылка «Повторение по расписанию».
- `data/mistakes.ts`: `mistakeWords(progress.data, limit)`, `mistakeTasks(progress.data, n = 10, pool = 30)`.

**Как собирается.** `mistakeWords`: слова из словаря с `bad > 0`, порядок: больше ошибок, потом выше доля ошибок, потом по номеру. Чужие ключи (не из словаря) пропускаются. `mistakeTasks`: из 30 первых слов берутся 10 случайных, на слово одно задание вида `tr`, `back`, `read` или `blank` (по порядку случайному). Набор собирается по кнопке и не меняется, пока не нажать «Другой набор», чтобы таблица не прыгала при ответах.

**Состояние и хранение.** Ничего своего. Данные из `progress.data.words` (ошибки считаются по всем тренажёрам, играм и «Сегодня»).

**Прогресс и награды.** Через `TaskSession`, `source: 'review'`.

**Тесты.** `tests/mistakes.test.mjs`.

**Как расширять.** Эти же функции используют `pairs.ts` и `SyllablesView.vue` (слабые слова идут первыми): меняя порядок или размер `mistakeWords`, проверь их.

**Подводные камни.** Галочка «выучено» у слова (`learned`) ставится по `KNOWN_STREAK` (5 верных подряд, `stores/progress.ts`); подсказка к ней берёт число из той же константы (раньше там было написано «три», исправлено 2026-11-08).
