# Частицы и окончания (`particles`)

**Что это.** Серия «вставь нужную форму» по одному правилу грамматики (частицы, окончания, связки) или вперемешку по всем.

**Где открыть.** `/game/home?game=particles`. Только по токену.

**Файлы.**
- `views/korean/ParticlesView.vue`: выбор правила чипами («Вперемешку» и по одному на правило; подпись чипа корейская, `title` русский), `TaskSession` (`source="trainer"`, `mode="particles"`), ссылка «Открыть правило» или «Вся грамматика».
- `data/korean/particles.ts`: `particleSets()`, `particleTasks(id, n = 10)`.
- Использует: `grammar.ts` (`G`), `rule-tasks.ts` (`ruleTasks`), `conjugation.ts` (`CONJUGATIONS`), `tasks.ts` (`shuffle`).

**Как собирается набор.**
- Правила берутся из карточек `st: 'ok'`, из примеров которых выходит не меньше трёх заданий «Вставь нужную форму» (`particleSets`).
- Для одного правила: все такие задания, перемешанные, не больше 10. «Вперемешку»: по 3 задания с каждого правила, перемешать, взять 10. Номера подряд.
- **Особые правила про формы слова** (`FORM_RULES`: `an` отрицание, `ayo` и `adj` вежливое настоящее): в примерах карточки отмечено одно и то же слово (например «안»), и «вставь форму» превратилось бы в «выбери 안». Для них берётся слово из таблицы форм и выбирается его форма среди соседних (настоящее, прошедшее, отрицание); примеров из карточки оставляется не больше двух.

**Состояние и хранение.** Выбранное правило в `usePersisted('particles_rule')` (sessionStorage), проверяется на существование. Набор собирается заново при смене правила и по «Ещё набор».

**Прогресс и награды.** Через `TaskSession`: `source: 'trainer'`, `mode: 'particles'`, монетки, предметы магазина. Слова (`word`) у этих заданий нет, очки слов не меняются.

**Тесты.** `tests/particles.test.mjs`.

**Как расширять.** Новое правило появится само, когда карточка получит статус `ok` и достаточно примеров с отметкой `{o|…}`/`{b|…}`. Если у правила всегда одно и то же отмеченное слово, добавь его в `FORM_RULES` и таблицу форм.

**Подводные камни.** Только пройденные карточки. Отметки в примерах (`{o|이에요}`) источник заданий: ломая разметку карточки, ломаешь тренажёр.
