# Похожие, но разные (`pairs`)

**Что это.** Задание на слово, где неверные варианты похожи на верное: из той же темы или с общими слогами. Сначала идут слова, в которых были ошибки.

**Где открыть.** `/game/home?game=pairs`. Только по токену.

**Файлы.**
- `views/korean/PairsView.vue`: пояснение над серией, `TaskSession` (`source="trainer"`, `mode="pairs"`), ссылка «Мои ошибки».
- `data/korean/pairs.ts`: `pairTask(w, id, reverse?)`, `pairTasks(progress.data, n = 10)`; название задания «Не перепутай».
- Использует: `words.ts` (`D`, `similarWords`), `data/mistakes.ts` (`mistakeWords`), `tasks.ts` (`shuffle`, `short`).

**Как собирается набор.** Слова с ошибками (до 30, перемешаны) идут первыми, дальше случайные слова словаря; на слово одно задание, пока не наберётся 10. Неверные варианты: `similarWords(w, 10)` без повторов перевода и самого слова, берётся до 3. Если похожих меньше двух, слово пропускается (`null`).
Направление случайное: слово → перевод (`tr`, подсказка с чтением) или перевод → слово (`back`).

**Состояние и хранение.** Ничего не запоминается.

**Прогресс и награды.** Через `TaskSession` (`word` заполнен, значит очки слова меняются), монетки, предметы магазина.

**Тесты.** `tests/pairs.test.mjs`.

**Как расширять.** Критерий «похожести» живёт в `similarWords` (`data/korean/words.ts`); менять его там, он влияет и на вкладку «Похожие слова» на странице «Слова».

**Подводные камни.** У слов без «соседей» задания нет, поэтому набор может собираться из слов не подряд.
