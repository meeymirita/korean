# Цепочки слов (`chain`)

**Что это.** Серия из 12 заданий по мотивам 끝말잇기. На экране опорное слово, нужно выбрать из четырёх слово, которое начинается с его последнего слога. Верное слово становится следующим опорным. Ровно один верный вариант: у трёх неверных первый слог другой. После ответа виден перевод опорного и верного слова (при ошибке в разборе ошибки). Ввода и звука нет.

**Где открыть.** `/game/home?game=chain`. Только по токену. Группа «Словарный запас».

**Выбор на уровне режима, а не нового движка.** Задание это обычное `Task`, серия идёт на `TaskSession.vue`. Новое только поле `Task.note` (пояснение после ответа): `TaskSession` показывает его под вариантами при верном ответе, а `explain()` подставляет его вместо общей фразы при ошибке.

**Файлы.**
- `views/korean/ChainView.vue`: экран (`TaskSession`, `source="trainer"`, `mode="chain"`).
- `data/korean/chain.ts` (чистые функции): `chainWords()`, `firstSyllableIndex()` (первый слог → слова), `continuations()`, `buildChain(idx, links)`, `distractors()`, `chainTasks(links = 12)`, `firstSyllable`, `lastSyllable`.
- `data/korean/tasks.ts` (`Task.note`), `data/korean/explain.ts`, `components/korean/TaskSession.vue` (абзац `.rs-note`).

**Как собирается набор.** Слова только из `STUDY` (не `D`, не `EXTRA`): хангыль без пробелов и скобок, от двух слогов, без повторов (512 слов). Слог берётся как есть, без правил произношения и 두음법칙. `buildChain` ищет путь из `links + 1` разных слов поиском с возвратом, поэтому слово без продолжения может быть только последним звеном и опорным не бывает. Неверные варианты: случайные слова с другим первым слогом, не из этой цепочки.

**Состояние и хранение.** Нет.

**Прогресс и награды.** Через `TaskSession`: монетки за серию, предметы магазина, отчёт по режиму `chain` («Цепочки слов», `EXTRA_MODES` и каталог). `word` не задан: очки слов не меняются (задание про слоги, а не про знание слова). Неверно отвеченное задание `TaskSession` повторяет через несколько шагов, поэтому порядок цепочки при ошибках может сбиться.

**Тесты.** `tests/chain.test.mjs`, `frontend/test/chain-view.spec.ts`.

**Как расширять.** Новые слова в `STUDY` подхватываются сами. Если нужны дополнительные связки (например, по произношению ㄹ → ㄴ), это правило владельца, сам не добавляй.

**Ограничения.** Из 512 слов у 372 есть продолжение в `STUDY`. Много глаголов и прилагательных кончаются на 다, и продолжения у них одни и те же (다리, 다시, 다섯); поиск с возвратом не даёт цепочке застрять на них, но встречаются они часто. В цепочке бывают слова без темы по уроку: это те же слова `STUDY`.
