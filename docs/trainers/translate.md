# Переведи предложение (`translate`)

**Что это.** Целое предложение: перевести на русский, на корейский или вперемешку, 4 варианта.

**Где открыть.** `/game/home?game=translate`. Только по токену.

**Файлы.**
- `views/korean/TranslateView.vue`: чипы направления (`TRANSLATE_DIRS`), `TaskSession` (`source="trainer"`, `mode="translate"`), ссылка «Все примеры с разбором» (`/korean/ref/sentences`).
- `data/korean/translate.ts`: `translateTasks(dir, n = 10)`, `TranslateDir = 'ko-ru' | 'ru-ko' | 'mix'`.
- Данные: `data/korean/translations.ts` (`TRANSLATIONS`: корейское предложение → русский перевод).

**Как собирается набор.** Пары предложение/перевод перемешиваются, на каждую делается задание. Неверные варианты: 3 предложения того же языка **похожей длины** (из случайных 40; чтобы ответ не угадывался по размеру), без повторов. `mix`: направление выбирается случайно для каждого задания. В `Task` кладутся `sentence` (разбор после ответа) и `pairOf` (чему соответствует каждый вариант на другом языке, чтобы объяснить ошибку).

**Состояние и хранение.** Направление в `usePersisted('translate_dir')`.

**Прогресс и награды.** Через `TaskSession`. У заданий нет `word`, поэтому очки слов не меняются.

**Тесты.** `tests/translate.test.mjs`.

**Как расширять.** Больше заданий = больше пар в `translations.ts` (там же правило: перевод для «я» нейтральный, без родовых форм о владельце). Новый вид (например, вставь пропущенное слово) делай новым файлом по образцу, а не усложняй этот.

**Подводные камни.** Переводы в `translations.ts` написаны мной, учитель их не проверяла (отмечено в `CLAUDE.md`).
