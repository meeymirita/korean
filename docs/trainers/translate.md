# Переведи предложение (`translate`)

**Что это.** Целое предложение: перевести на русский, на корейский или вперемешку, 4 варианта.

**Где открыть.** `/game/home?game=translate`. Только по токену.

**Файлы.**
- `views/korean/TranslateView.vue`: чипы направления (`TRANSLATE_DIRS`), `TaskSession` (`source="trainer"`, `mode="translate"`), ссылка «Все примеры с разбором» (`/korean/ref/sentences`).
- `data/korean/translate.ts`: `translateTasks(dir, n = 10, level)`, `TranslateDir = 'ko-ru' | 'ru-ko' | 'mix'`, `TRANSLATE_LEVELS`.
- Данные: `data/korean/translations.ts` (`TRANSLATIONS`: корейское предложение → русский перевод).

**Уровни** (второй ряд чипов, `TRANSLATE_LEVELS`, по длине корейского предложения в слогах хангыля): «Любой», «Простой» (до 6 слогов, 177 предложений), «Средний» (7–8, 180), «Сложный» (9 и больше, 197). Неверные варианты берутся из всех предложений, ограничение уровня только у самого задания.

**Как собирается набор.** Пары предложение/перевод (выбранной длины) перемешиваются, на каждую делается задание. Неверные варианты: 3 предложения того же языка **похожей длины** (из случайных 40; чтобы ответ не угадывался по размеру), без повторов. `mix`: направление выбирается случайно для каждого задания. В `Task` кладутся `sentence` (разбор после ответа) и `pairOf` (чему соответствует каждый вариант на другом языке, чтобы объяснить ошибку).

**Уровень «Текст» (2026-11-09):** отдельный чип рядом с уровнями по длине (`TEXT_LEVEL`, `textTasks` в `translate.ts`): переводится целый рассказ из `game/stories.ts` (10 рассказов, 2–7 предложений, из учебника), неверные варианты это другие рассказы похожей длины; серия состоит из всех рассказов по разу. Тест `tests/translate.test.mjs`.

**Рядом:** «Переведи и объясни» (`explain.md`) использует `sentenceTask()` и `pairIndex()` отсюда (одно задание на предложение).

**Состояние и хранение.** Направление в `usePersisted('translate_dir')`, уровень в `usePersisted('translate_level')`.

**Прогресс и награды.** Через `TaskSession`. У заданий нет `word`, поэтому очки слов не меняются.

**Тесты.** `tests/translate.test.mjs`.

**Как расширять.** Больше заданий = больше пар в `translations.ts` (там же правило: перевод для «я» нейтральный, без родовых форм о владельце). Новый вид (например, вставь пропущенное слово) делай новым файлом по образцу, а не усложняй этот.

**Подводные камни.** Переводы в `translations.ts` написаны мной, учитель их не проверяла (отмечено в `CLAUDE.md`).
