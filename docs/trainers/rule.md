# Потренировать правило (`rule`)

**Что это.** Серия из 10 заданий из примеров выбранной карточки грамматики. Работает для любой карточки с примерами, в том числе для новых.

**Текст по правилу (2026-11-09):** у карточек про 은/는, 이/가, 을/를, 에 и 하고 в окне карточки есть вторая кнопка «Текст по правилу» (`GrammarModal.vue`, `famOfCard` из `game/families.ts`): она открывает режим «Тексты по правилу» (`?game=ptext&fam=<правило>`, `bread-game.md`) с предложениями и рассказами про эту частицу.

**Где открыть.** `/game/home?game=rule&g=<id карточки>` (id из `grammar.ts`). Без `g` показывается выбор из списка. На странице грамматики у карточки есть кнопка «Потренировать это правило». Только по токену.

**Файлы.**
- `views/korean/RuleView.vue`: выпадающий список карточек (`<select>`, группы «Мои карточки», «Часть 1», «Часть 2» через `tabOf`), `TaskSession` (`source="trainer"`, `mode="rule"`, кнопка «Ещё серия»), ссылка «Открыть карточку».
- `data/korean/rule-tasks.ts`: `ruleSession(g, n = 10)`, `trainableRule(g)`, а также `ruleTasks(g, n = 3)` для «Сегодня» и «5 минут»; `RULE_TASK_BASE = 1000`.
- Данные: `data/korean/grammar.ts` (блоки `['ex', [[ko, ru], …]]`).

**Как собирается набор.** Часть примера, которую правило меняет, в карточке отмечена `{o|…}`, `{b|…}`, `{r|…}`. По каждому примеру `ruleSession` делает до четырёх видов заданий:
1. «Вставь нужную форму» (если в примере ровно одна отметка; неверные варианты: сначала части этого же правила, потом чужие);
2. «Какое предложение верное?» (неверные получаются подменой отмеченной части);
3. «Что значит предложение?»;
4. «Как это по-корейски?».
Виды берутся по кругу (чтобы серия была разной), предложения не повторяются, номера с 1000. Карточка подходит, если в ней минимум 3 примера (`trainableRule`).
`ruleTasks` (3 задания, два вида) отличается: чужие примеры берутся только из карточек `st: 'ok'`.

**Состояние и хранение.** Выбранная карточка в адресе (`?g=`), список обновляет адрес через `router.replace`. Серия пересобирается при смене карточки и по «Ещё серия».

**Прогресс и награды.** Через `TaskSession`. Заданий со словом нет, очки слов не меняются; в разбор ошибки идёт `gram`.

**Тесты.** `tests/rule-tasks.test.mjs`.

**Как расширять.** Новый вид задания добавь в `ruleSession` (отдельный список вроде `fill`/`right`) и в круг `lists`. Новая карточка с примерами подхватится сама, если примеры размечены `{o|…}`.

**Подводные камни.** В списке видны **все** карточки с тремя и более примерами, в том числе со `st: 'soon'` (владелец ещё не отметил пройденными): это отличие от «Сегодня» и «5 минут», где только `ok`. Чужие примеры для неверных вариантов в `ruleSession` берутся из всех карточек.
