# Определи часть речи (`speech`)

**Что это.** Серия из 15 слов: выбери, что это, глагол, прилагательное или вопросительное слово. Показано корейское слово и его перевод. После ответа: «почему» (что называет слово и его вежливая форма; у неверного ответа это строка разбора ошибки `ExplainBox`) и пример слова в предложении из `STUDY_TRANSLATIONS` с разбором «Как собрано».

**Где открыть.** `/game/home?game=speech`. Только по токену. Группа «Словарный запас».

**Файлы.**
- `views/korean/PartOfSpeechView.vue`: экран (`TaskSession`, `source="trainer"`, `mode="speech"`).
- `data/korean/part-of-speech.ts`: `posWords()`, `posWhy(w)`, `pickPosSet(words, n)`, `posTasks(n = 15)`, `POS_LABEL`, `POS_OPTIONS`.
- Данные: `VERBS`, `ADJECTIVES`, `QWORDS` (`data/korean/forms.ts`, из `game/words.ts`), `STUDY`, `STUDY_TRANSLATIONS`.

**Откуда часть речи.** В словаре платформы поля части речи нет (`Word` это `k, r, t, s, c`; `c` это темы, а не части речи; часть речи есть только в большом словаре `/dict` на сервере). Поэтому она выводится из готовых наборов: глаголы из `VERBS` (58 в `STUDY`), прилагательные из `ADJECTIVES` (31), вопросительные слова из `QWORDS` (7). Берутся только слова, которые есть в `STUDY` (не `EXTRA`). `있다` и `없다` исключены: у них часть речи зависит от значения.
Существительных, наречий, местоимений и связки здесь нет сознательно: слова не угадываются. Остальные слова на `하다` (`등산하다`, `미안하다`…) тоже не берутся: глагол это или прилагательное, из данных не видно.

**Как собирается набор.** `pickPosSet`: поровну по трём частям речи (по 5 из 15; вопросительных слов всего семь, недостающее добирается из остальных), без повторов слов, порядок перемешан. Задание это обычное `Task` (`kind: 'tr'`, три варианта в фиксированном порядке, `note` с объяснением, `sentence` только если пример есть в `STUDY_TRANSLATIONS`).

**Состояние и хранение.** Нет.

**Прогресс и награды.** Через `TaskSession`: монетки за серию, предметы магазина, отчёт по режиму `speech` («Определи часть речи», название из `ALL_GAMES`). `word` не задан: очки слов не меняются (проверяется часть речи, а не значение слова).

**Тесты.** `tests/part-of-speech.test.mjs`, `frontend/test/part-of-speech.spec.ts`.

**Как расширять.** Нужна разметка части речи у слов словаря (хотя бы существительное и наречие): тогда в `posWords()` добавится новый вид и вариант в `POS_LABEL` / `POS_OPTIONS`. Слова в словарь сам не добавляй и часть речи не угадывай.

**Ограничения.** Три вида ответа вместо привычных пяти-шести; все слова пройденные (`STUDY`). Название «Определи часть речи» в шторке и каталоге при этом шире, чем набор: в описании сказано «глагол, прилагательное или вопросительное слово».
