# Чтение и диалоги (`read`)

**Что это.** Тренажёр из двух серий на `TaskSession`, переключатель «Рассказы» / «Диалоги» вверху (`?kind=stories|dialogs` в адресе, по умолчанию рассказы).
- **Рассказы:** 8 заданий. Над вопросом виден весь корейский рассказ из учебника (`STORIES`, `game/stories.ts`), вопрос по смыслу по-русски и четыре варианта (верный и три неверных). После ответа: разбор предложения, на которое опирается ответ, и его перевод («В рассказе: …»). Не больше двух вопросов по одному рассказу.
- **Диалоги:** две сценки подряд (по 4 реплики, всего 8 заданий). Собеседник спрашивает (реплика из `EXCHANGES`, `game/dialogs.ts`), нужно выбрать из трёх ответ; прошлые реплики сценки видны над вопросом, под вопросом его перевод. Неверные ответы взяты из реплик другой темы (тег `EXCHANGES`), поэтому они точно не подходят; после ошибки показано, на какой вопрос подходит каждый вариант.

**Где открыть.** `/game/home?game=read` (группа «Общение и вежливость»). Только по токену.

**Файлы.**
- `views/korean/ReadView.vue`: экран (переключатель серий, `TaskSession`, `source="trainer"`, `mode="read"`).
- `data/korean/read.ts`: `READ_QUESTIONS` (21 вопрос по 10 рассказам, написаны вручную), `readTasks(n = 8)`, `SCENES` (5 сценок: знакомство, дни и планы, в комнате, еда, куда идёшь), `sceneTasks(n = 2)`.
- Данные: `STORIES`, `EXCHANGES`; общий компонент `components/korean/TaskSession.vue`. В `Task` добавлено необязательное поле `small` (вопрос не крупным шрифтом), в `TaskSession` заголовок из нескольких строк показывается плашкой (`rs-pre`, стили в `assets/cabinet.css`).

**Как собирается набор.** Рассказы: вопросы перемешиваются, берутся первые восемь с лимитом два на рассказ. Диалоги: перемешиваются сценки, берутся две, реплики идут по порядку; два неверных ответа выбираются из `EXCHANGES` с другим тегом и другим текстом, чем верный.

**Состояние и хранение.** Нет (серия не запоминается; переключатель серий в адресе).

**Прогресс и награды.** Через `TaskSession`: монетки за серию, предметы магазина, отчёт по режиму `read` («Чтение и диалоги», название из `ALL_GAMES`). `word` не задан: очки слов не меняются.

**Тесты.** `tests/read.test.mjs` (вопросы и сценки: варианты, предложения разбираются без неизвестных слов, неверные ответы от другой темы), `frontend/test/read-view.spec.ts`.

**Как расширять.** Новый вопрос по рассказу: строка в `READ_QUESTIONS` (рассказ, вопрос, верный ответ, три неверных, номер предложения, на которое опирается ответ); ответы пиши по русскому переводу рассказа в `STORIES`, неверные не должны быть правдой по тексту. Новая сценка: список реплик в `SCENES`, каждая реплика должна быть в `EXCHANGES` (тест следит). Новые рассказы и реплики добавляй в `game/stories.ts` и `game/dialogs.ts` (слова только из словаря, перевод без рода, `docs/data.md`, «Проверка нейросетями»).

**Ограничения.** Вопросы по рассказам написаны вручную и проверены только мной; перед правкой текста вопросов покажи владельцу. Переводы рассказов мои, учитель их не проверяла. Сценки короткие (4 реплики).
