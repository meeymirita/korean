# Игра «Хлебушек» (`src/game`)

`engine.ts` — императивный JS из старого `Hlebushek_Game.html` с `// @ts-nocheck`, работает на разметке
`markup.html` (вставляется через `v-html`), стили `game.css` (все правила с префиксом `.game`), состояние в
`localStorage` (`hleb_game_v1`: настройки, статистика, уровень/очки/цель дня, слабые слова). Режимы: микс, слово→
перевод, перевод→слово, формы, вопросы, частицы и счёт, **собери предложение**, **найди верное**, **напиши**.
Новые режимы (генераторы в `engine.ts`, диалоги в `src/game/dialogs.ts`): **найди ошибку** (`genErr`: из банков `D.PB`/`D.QB`
подставляется неверная частица/слово, нажимаешь на слово), **пара или нет** (`genPair`: 은/는, 이/가, 을/를, 이에요/예요 по 받침
слов из `D.S` и пары 에/에서), **порядок слов** (`genOrd`: слово из `makeBuild`, выбор предложения с верным местом),
**диалог** (`genDlg`, 20 реплик со своими переводами, ответы чужих тем как неверные), **прошедшее время** (`genPast`:
«어제 ___» / «지금 ___»), **хангыль-блиц** (`genHan`: слог из букв и чтение слога, 14 согласных × 10 гласных). Клавиши 1–9
выбирают ответ. Кнопка «🔄 Обновить вопрос» (`#refreshBtn` под карточкой) заменяет текущий вопрос другим в том же режиме, ответ не засчитывается. Режим открывается ссылкой `/game?mode=<id>` (`hooks.mode`). Когда слово впервые становится выученным,
`record` возвращает `bloomed`, и игра показывает «расцвело в саду».
Плюс блиц 60 с, **выживание** (3 жизни), **подсказка 50/50** (клавиша H, 3 на игру), уровень (звания от «Ученицы» до
«Великого мага»; уровень L нужен 50·L·(L−1) очков, +10/15/20 за ответ, +5 за каждые 5 в серии), **цель дня** 20.
Ошибки возвращаются чаще (вес по `S.miss`), у «собери предложение» повтор по зерну.

**Собери предложение** (`build.ts`): 3 уровня, шаблоны (простой — 2 слова, средний — 3–4, сложный — 5–7: время,
кто, с кем, где, «А и Б», отрицание `안`, заказ с числами). Корейский и русский текст строятся из одних и тех же
слов, частицы по 받침; лишние плитки с неверной частицей/временем/местом; допустимы разные порядки внутри групп
(`g` у чанков); ключ вопроса `b:уровень:время:зерно`. Кнопка «Показать переводы» (клавиша T) подписывает плитки,
клавиши 1–9 выбирают слово. Проверено на ~790 уникальных предложениях, все разбираются `parse.ts`.

**Правки 2026-10-31.**
- Разбор после ответа (`showFeedback`) не закрывается сам: переход только кнопкой «Дальше →» или Enter. Исключение — режим «Блиц» (`S.blitz.on`), там автопереход через 0,45 с после верного и 1,1 с после неверного. Галочка «после верного ответа сразу дальше» и поле `S.auto` убраны.
- Боковая панель: вкладки «История», «Слабые слова», «Слова» (поиск `#wq` по `ko`/чтению/переводу, до 60 результатов).
- Подсказки режимов: `MODE_HELP` в `engine.ts` (описание и пример на каждый режим), `labelWithHelp(q)` рисует «?» рядом с заданием; в первый раз в каждом режиме подсказка открыта (`S.modeHelp`, сохраняется). Тест `tests/grammar-data.test.mjs` следит, что у каждого режима есть подсказка с примером; **новый режим добавляй и в `MODES`, и в `MODE_HELP`**.
- «Найди ошибку» (`genErr`) берёт только пары, где правильный вариант из одного слова: иначе предложение делится на слова по пробелам и «слово с ошибкой» находилось неверно.
- В запись ответа уходят подробности: `hooks.record({ …, detail: { q: q.hp, a: q.hr, y: chosen } })`, они попадают в историю кабинета.
- Шапка страницы (`GameView.vue`): слева «☰ Меню» (список разделов по наведению; на планшете по нажатию), справа «Поиск», «Сад», «Словарь» (`.game-pill`); глобальной кнопки поиска (`GlobalSearch`) на `/game` нет, окно то же.
