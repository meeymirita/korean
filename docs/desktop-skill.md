## Отправка материалов на 우리말 через API

База: `https://korean.meeymirita.ru`. Всё, что я отправляю, попадает только во «Входящие». Владелец сам решает, что оставить. В словарь и грамматику я ничего не вношу.

### Токен
- Пользователь создаёт сам кнопкой «Токен для Claude: запись». Токен записи живёт **60 минут**, токен чтения 10 минут. Он только читает входящие и добавляет, не правит и не удаляет.
- Пользователь прислал токен чтения или токен истёк: прошу токен записи.
- Токен нигде не сохраняю (ни в файлах, ни в памяти) и не использую вне этих запросов.
- Ответ 401: останавливаюсь, прошу свежий токен записи, старый не повторяю.
- Источник истины по сценариям: раздел `workflow` и список `topics` в `/api/public/rules`. Перед работой перечитываю его (кэш до минуты; если вижу старую версию без `workflow`, добавляю параметр, например `?v=2`). Навык расходится с `workflow`: прав `workflow`.
- Сообщение с токеном после моих результатов в чате = команда отправлять (см. подтверждения).

### Перед каждой отправкой
Читаю: `GET /api/learning` (с токеном), `GET /api/public/rules` и `GET /api/materials/format` (последние два без токена). Корейские предложения проверяю:
- все слова есть в `https://korean.meeymirita.ru/words.json` (слова нет: заменяю или показываю пользователю);
- нет дублей с `/api/public/sentences`;
- не срабатывают правила `forbid` из `/api/public/rules`. Шаблоны рассчитаны на JavaScript (флаги `iu`); в Python использую модуль `regex` или Node, иначе проверяю глазами;
- грамматика только из `learning.grammar.passed`, темы из `notYet` не использую;
- русское «я» без рода («устал(а)»), имена только из `conventions`.

### POST /api/materials (одним запросом, до 200 элементов)
Тело: `{"source": "...", "kind": "workbook|textbook|notebook|lera|other", "items": [...]}`.

Типы элементов: `word` (ko, ru; reading, example, note), `sentence` (ko; ru, topic), `dialog` (lines [{ko, ru}], от 2), `text` (sentences; title, questions [{q, options 2–6, answer номер с нуля}]), `grammar` (title; note, examples [{ko, ru}]), `exercise` (prompt; body, answer), `task` (title; body, topic), `mistake` (mine, right; no, why, topic), `note` (text). Лимиты по типам смотрю в `/api/materials/format` (`itemTypes`).

### Что и как отправлять
- **Проверка тетради** (фото выполненного задания). Проверяю построчно, при неясном почерке сначала спрашиваю. В чате короткая сводка и PDF-таблица ошибок, как заведено. После результатов в чате и токена отправляю ошибки без дополнительного «да»: каждая значимая ошибка отдельным `mistake` (mine, right, why, no, topic). Поле `mine` содержит только то, что написано в тетради, без пометок вроде «сам исправил»: пояснения идут в `why`. `source` «Тетрадь, <тема>, <дата>», `kind` notebook. `topic` беру только из `topics` в `/api/public/rules`, новых названий не придумываю; нужной темы нет: «другое». Не отправляю мелочи (точки, запятые, пропущенные знаки, явные описки). Само задание можно добавить одним `task`, если его ещё нет.
- **Слова с учебника или рабочей тетради.** Беру слова со страницы; слова, уже имеющиеся в `words.json`, не отправляю. Каждое слово как `word` (ko, reading, ru, example из известных слов). Они попадают во «Входящие» и «Новые слова». `source` «Учебник 1A, урок N» / «Workbook, стр. N».
- **Тексты, диалоги, упражнения, правила со страницы:** только то, что реально есть на странице, в соответствующие типы. Нужного типа нет: `note` или ничего. Ничего не выдумываю.
- **Задания, которые составляю я:** слабые слова из `learning.words.weak`, грамматика из `grammar.passed`, темы из ошибок. Отправляю как `task` с русскими фразами и без ответов; ключ остаётся у меня.

### Подтверждения
- Без «да»: всё, что берётся со страницы или из тетради (слова из учебника, тексты, диалоги, упражнения, правила, проверка тетради). Оно идёт только во «Входящие», решает владелец. В чате одна строка: «отправил N штук, пачка <id>».
- С «да»: только то, где я сам придумываю содержание (свои слова или предложения, составленное мной задание). Сначала показываю в чате таблицей, что отправлю, и жду «да». «Да» может прийти вместе с токеном.

### После отправки
Проверяю ответ (201, id пачки, counts, wordsAdded). Ничего из API в основной словарь или грамматику не переношу.
