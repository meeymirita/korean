# Данные (сайт — единственный источник) и разбор предложений

С 2026-11-04 источник правды — сайт: данные лежат файлами в `frontend/src/data/korean/`. Notion больше не ведётся как словарь. Новые слова владелец пишет в локальный `материалы/новые-слова/НОВЫЕ.md` (не в git) и просит «разнеси слова».

## Словарь (`dictionary.ts`)
`RAW` (`n, k, r, t, s`: слово, чтение, перевод, пример), `CAT` (категории), `SYN` (формы для поиска: «ем» → «есть»), `CATN`. Сейчас 661 слово (с 2026-11-09 добавлено 16 слов из урока 6 «날짜와 요일», тетрадь WB 118–123: даты, 시험, 등산하다 и др.; с 2026-11-08 добавлено 78 слов из материалов учебника: страны, языки, еда, места, вещи, определительные числа 한/두/세/네 и счётные 명/마리/권/장; имена героев учебника не в словаре, а списком `NAMES` в `parse.ts`; с 2026-11-08 добавлены 고마워, 고마워요, 감사합니다 для разбора в «Уровне вежливости», тема «эмоции»; с 2026-11-03: 25 слов про дни недели и время от Леры, новая тема `время` = «Время и дни», в `CATN` и в `CAT`; слова про время лежат в нескольких темах сразу).
В `RAW.t` чистая форма перевода; формы глаголов живут в `src/game/words.ts` (`D.V`, `D.A`: слово, чтение, перевод, настоящее, прошедшее, пояснение).
**Страница «Слова»:** видны первые 100 слов, остальные открываются кнопкой «Показать ещё» (по 100); в разметке для поисковиков остаются все слова (скрыты через `v-show`), поиск и смена темы снова показывают первую сотню. Тест `frontend/test/words.spec.ts`.
**Добавил слово** (из `материалы/новые-слова/НОВЫЕ.md`: допиши чтение, пример, тему, перенеси строки в «Внесено»)**:** запусти `node scripts/digest-pool.mjs`, `node scripts/build-words-json.mjs` и `node scripts/chat-curriculum.mjs` (тесты следят), добавь перевод предложения в `translations.ts`, в Notion слова больше не вносим.

**Публичный `/words.json`** (`frontend/public/words.json`, собирает `scripts/build-words-json.mjs`, тест `tests/words-json.test.mjs`): все слова только для чтения (`n, ko, reading, ru, categories, example, example_ru`). Нужен, чтобы чат-помощник (читает лишь открытые адреса) сверял новые слова на дубли. Личного там нет: ни токенов, ни прогресса, ни «выучено». Отметки «напечатано» нет по решению владельца. На сайт попадает после деплоя.

## Записанные слова («Добавить слово» на странице «Слова»)
Кнопка «+ Добавить слово» (только после входа по токену) открывает шторку `NewWordDrawer.vue`: форма (корейский, чтение, перевод, предложение, заметка до 3000 знаков; нужны слово и перевод либо хотя бы заметка) и раскрывающийся блок «Записанные слова». Данные лежат в таблице `new_words` (миграция `20261108000000_new_words`), стор `stores/newWords.ts`, сервер `backend/src/newwords` (`/api/new-words`, только владелец, гость и так ничего не сохраняет). Над формой подпись с путём слова: записал → Claude смотрит → проверка в krdict → обсуждение → добавление. **Это не словарь, а «входящие»**: в `dictionary.ts` слова не попадают сами.
**Как Claude берёт эти слова: только через API, без захода на сервер.** В шапке шторки кнопка «Создать токен» (рядом «?» с пояснением): сервер выдаёт случайный токен на 10 минут (в `meta` только его хэш и срок, новый токен отменяет прежний, «Отозвать» закрывает сразу). Владелец копирует токен и присылает в чат, дальше `INBOX_TOKEN=<токен> BASE=https://korean.meeymirita.ru node scripts/inbox.mjs` (`GET /api/new-words`). Токен только читает список: запись, удаление и остальные маршруты ему закрыты (403), после срока 401. Постоянного токена в `.env` нет. Дальше обычный порядок: слова добавляются в `dictionary.ts` по слову владельца («разнеси слова»), заметки читаются и обсуждаются, внесённое владелец удаляет в шторке сам. Прямого доступа к базе у Claude нет.

## Грамматика (`grammar.ts`, `G`)
Источник правды: сам файл `grammar.ts`. Новые карточки дополняются из PDF владельца (`материалы/ГГГГ-ММ-ДД/`), порядок описан в `CLAUDE.md`.
Статусы: `ok` (пройдено, идёт в «Сегодня», тренажёры и игру) или `soon` («ещё рано»: пустые заглушки, а также карточки, которые владелец ещё не отметил пройденными)  Карточки «에 (когда)» и «도 (тоже)» от Леры владелец отметил пройденными 2026-11-04 (`ok`), дополнены из его PDF (`материалы/…/граматика`). **Вкладки страницы `/korean/grammar`** (`tabOf` в `grammar.ts`): 0 «Мои карточки» (все без подписи урока `l`: с Лерой и свои), 1 «Часть 1» и 2 «Часть 2» (карточки уроков видеокурса); темы в «Моих» и в видеоуроках могут повторяться (например, «에 (время)» есть и там, и там), разграничение пока не делали. `part`: 1 (по умолчанию) или 2 («Второй шаг»). **Подпись урока `l` только у карточки урока курса, ровно одна на видео**; свои карточки владельца без `l`.
Видео: `course.ts` (`videoOf`, `VIDEO_DIR`), оригинальные названия роликов `videoTitles.ts`. Блоки карточки: `['p'|'h'|'rule'|'formula'|'warn'|'tip'|'ok'|'pron'|'ex'|'tbl', ...]`, цвета в тексте `{o|…}` (есть 받침) и `{b|…}` (нет).
Темы второго шага взяты из имён файлов видео.

## Переводы предложений (`translations.ts`)

## Разбор предложений (`parse.ts`)
`analyze(sentence)` режет предложение на слова, частицы и окончания: словарь `LEX` из `dictionary.ts` и форм глаголов `forms.ts` + служебные слова (`FUNC`), имена героев учебника (`NAMES`, омоним 마리 решает `HOMONYM_NAMES`) и формы из примеров, которых нет в `forms.ts` (`FORMS`: 맑아요, 갈게요…, только для разбора, в тренажёры не попадают), вежливое 요 после частицы («저도요»); частицы по 받침 (`은/는`, `이/가`, `을/를`, `이에요/예요`, `으로/로`…), `-해요`, числа, счётные слова,
слова из двух частей, имена. Неизвестное: карточка «?». Используется в `SentenceBreakdown.vue` и в игре. Покрытие закреплено `tests/parse.test.mjs` (порог поднимать, не снижать).

## Культура Кореи (`/korean/culture`)
`CultureView.vue` + `data/korean/culture.ts`: карточки по трём темам (еда, праздники, этикет) с фильтром, во вкладке «Все» вперемешку попадаются слова из словаря. Новую карточку допиши в `CULTURE` (тест `tests/culture.test.mjs`).

## «Что я уже знаю» (`/korean/know`) и «Полезные сайты» (`/korean/sites`)
`KnowView.vue`: пройденные карточки грамматики (`st: 'ok'`, без снятой отметки) по номерам уроков: формула и первый пример берутся из блоков карточки. Своих данных у страницы нет. `SitesView.vue` + `data/korean/sites.ts` (`SITE_GROUPS`): внешние ссылки по группам, тест следит за https-адресами и повторами.

## Мастерская грамматики (`/korean/lab`)

`LabView.vue` + `data/korean/lab.ts`, четыре вкладки (`?tab=`): конструктор (слово + частица + глагол из `CONJUGATIONS`, форма частицы по 받침 в `attach`), дерево тем (`DEPS`: id карточки → от чего зависит, уровни считает `depthOf`), «Почему так» (`WHY`, привязано к id карточек) и два стиля (`STYLES`: вежливо и разговорно, только пройденное время). Новые карточки грамматики: допиши зависимость в `DEPS`, тест `tests/lab.test.mjs` следит за id и циклами.

## Большой словарь (`/dict`)

Отдельный раздел с собственной документацией: [`docs/dict.md`](dict.md). Это не словарь платформы (`dictionary.ts`, 600+ слов владельца), а поиск по всей базе krdict (53 тысячи слов). В словарь платформы слова из него попадают только по слову владельца.
