# Каталог игр и тренажёров

Разработческая шпаргалка (подробные описания тренажёров в [`docs/trainers/`](trainers/README.md)): что уже есть в играх и тренажёрах платформы, чтобы не пере-сканировать проект
перед каждой новой идеей. **Обновляй этот файл, когда меняешь режим, добавляешь тренажёр или новую игру**
(как и шторку «Что здесь есть», `src/data/guide.ts` — но та для пользователя, этот файл для разработки).

Источники правды, на которые этот файл ссылается (если расходятся — верь им, а не этому файлу):
- `src/data/games.ts` — список всех игр/тренажёров каталога `/game/home` (группы, иконки, описания, `TOOL_IDS`)
- `src/game/engine.ts` — движок «Хлебушек»: `MODES`, `MODE_HELP`, вся логика режимов
- `src/data/guide.ts` — те же описания, но для пользователя (шторка «Что здесь есть»)

## Встроенная игра «Хлебушек» — `/game/home?game=<id>`

Один движок на все 24 режима (в 25 из них, а также в блице и на выживании, у части есть уровни-тексты «Рассказ» и «Длинный», см. `docs/trainers/bread-game.md`) (14 общих и 10 по темам грамматики): `src/game/engine.ts` (`initGame()`, без типов — `@ts-nocheck`, чистый DOM
без Vue), разметка `src/game/markup.html`, стили `game/game.css` + `redesign.css` + `shell.css`. Хук прогресса
и переключение режимов — `GameHomeView.vue`. Слова движка свои (`src/game/words.ts`), это не тот же массив,
что общий словарь `data/korean/words.ts`.

| id | Название | Что делает | Особое |
|---|---|---|---|
| mix | Микс | Вопросы всех режимов вперемешку | — |
| word | Слово → перевод | Корейское слово → перевод, 4 варианта | — |
| rev | Перевод → слово | Русское слово → корейское, 4 варианта | — |
| form | Выбери форму | Глагол/прилагательное: наст./прош. время, вежливый стиль | иногда с «вчера»/«сейчас» |
| qw | Вопросы | Вставь вопросительное слово (어디/누구/뭐/얼마/몇) | — |
| part | Частицы и счёт | Вставь частицу или счётное слово | данные — `D.PB` в `game/words.ts` |
| build | Собери предложение | Собери из плиток (есть лишние) | **3 уровня сложности** (`LEVEL_NAME`, `game/build.ts: makeBuild()`); морфологический разбор плиток — `analyze()`/`tileGloss()` из `data/korean/parse.ts` (та же функция, что в `SentenceBreakdown.vue` для разбора примеров словаря) |
| spot | Найди верное | Из 4 предложений верное одно | — |
| type | Напиши правильную форму | Ввод формы с клавиатуры + подсказка по буквам | свой текстовый ввод внутри движка (не тот же компонент, что `TypingQuiz.vue`) |
| err | Найди ошибку | Клик на неверное слово в предложении | — |
| pair | Пара или нет | Выбор частицы/формы из двух | — |
| ord | Порядок слов | Слово нужно поставить на место | — |
| dlg | Диалог | Реплика → подходящий ответ из 3 | данные — `src/game/dialogs.ts` (`EXCHANGES`). **Уже реализован**, это не пустышка |
| han | Хангыль-блиц | Собери слог из букв / прочитай слог | данные — `data/alphabet.ts` |
| days | Дни недели | Перевод, «какой день завтра или был вчера», будни или выходные | `genDays` |
| when | Когда? (에) | Нужна ли частица времени, исключения 오늘, 내일, 지금, 언제 | `genWhen` |
| too | Тоже (도) | 도, 에도, 에서도 | `genToo` |
| num | Числа | Число и цифра, корейский и китайский счёт | `genNum` |
| price | Сколько стоит? | Прочитать цену в вонах | `genPrice`, `sinoNum` |
| count | Счётные слова | Вставь счётное слово или число (병, 잔, 개, 명…) | `genCount`, банк `D.PB` |
| neg | Это или не это | 이에요/예요 и 이/가 아니에요 по 받침 | `genNeg` |
| place | Куда, где | 에 или 에서 при месте | `genPlace` |
| dem | Этот, тот, вон тот | 이/그/저, 이것/그것/저것, 여기/거기/저기 | `genDem` |
| polite | Уровень вежливости | «Спасибо» от 고마워 до 감사합니다 | `genPolite` |

Оверлеи поверх любого режима (не отдельные `id`, переключаются кнопками в `GameHomeView.vue`):
- **Блиц 30 / 60 / 120 секунд** — `S.blitz` в `engine.ts`, длина в «Настройках» (`S.blitzSecs`), рекорд `S.all.bestBlitz` (для 60 с) и `bestBlitzBy`
- **На выживание** (3 / 5 жизней или без ограничения, `S.survLives`) — `S.surv`, рекорд `S.all.bestSurv` (для 3 жизней) и `bestSurvBy`

Общие на всю игру рекорды: `S.all{ok,bad,best,bestBlitz,bestSurv,xp}` и `S.ses{ok,bad,streak,best}` в `engine.ts`.
Рекорды по каждому режиму — `S.all.byMode[id]{ok,bad,best}`, обновляются в `finish()`, показываются вкладкой
«Рекорды» (`#tabRecords`) рядом с «История» / «Слабые слова» / «Слова» в `markup.html`. Обнуляются вместе с
остальной статистикой игры кнопкой «Сбросить статистику игры».

Подсказка по режиму (кнопка «?» на экране задания) — `MODE_HELP` в `engine.ts`; тест `tests/grammar-data.test.mjs`
следит, что у каждого `id` из `MODES` есть запись в `MODE_HELP`.

## Отдельные тренажёры (Vue-компоненты) — тоже на `/game/home?game=<id>`

Не часть движка: свои компоненты, подключаются в `GameHomeView.vue` через `TOOLS` (список id — `TOOL_IDS` в `data/games.ts`).
**Подробности по каждому (файлы, как собирается набор, что сохраняется, что идёт в прогресс) в `docs/trainers/`; здесь только указатель, чтобы не держать одно и то же в двух местах.**

его, не пиши цикл заданий заново.

## Где искать перед новой идеей (чтобы не задублировать)

- **Новый вопрос-ответ режим** (текст вопроса, несколько вариантов) → `TaskSession.vue` + новый файл в
  `data/korean/`, по образцу `particles.ts` / `pairs.ts`.
- **Разбор слова по составу / морфология** → уже есть, `data/korean/parse.ts` (`analyze`); используется и в
  режиме `build`, и в разборе примеров словаря (`SentenceBreakdown.vue`). Не писать новый парсер.
- **Диалоги** → данные уже есть, `game/dialogs.ts`, подключены как режим `dlg`. Расширять — там же.
- **Объяснение «почему так» у грамматики** → короткие тексты `WHY` в `data/korean/lab.ts` (вкладка «Почему так»
  в «Мастерской») и блоки `['tip', текст]` в `Gram.b` (`data/korean/grammar.ts`). Не заводить третье место.
- **Зависимости тем, конструктор, вежливый и разговорный стиль** → уже есть, `data/korean/lab.ts` (`DEPS`, `build`, `STYLES`).
- **Готовая выжимка по пройденному** → шаблон уже есть, `data/korean/pages.ts` (`cheatHtml` / `talkHtml` / …),
  рисуется `RichView.vue` во вкладках `ref/*`.
- **Личная статистика / графики** → в кабинете уже есть вкладка отчётов: `ReportTab.vue` + `ReportChartModal.vue`
  + `data/report.ts`, сервер — `GET /api/report/*`. Расширять её, не заводить вторую вкладку аналитики.
- **Напоминание на своё время** → готовый паттерн `{enabled, time, lastSent}` в
  `backend/src/reminders/reminder.service.ts` и `backend/src/digest/digest.service.ts` (оба тикают раз в минуту).
  Свои дни недели (`days`) уже есть; напоминание о созвоне с учителем (`backend/src/lesson/`) устроено так же. Расширять эти сервисы, не заводить новые.
- **Отметка «когда достигнуто»** → у слов `WordStat.kd` (`stores/progress.ts`), у достижений `lib/achievedDates.ts`
  (только в браузере).

Названия, иконки и маршруты для пользователя отдельно поддерживаются в `src/data/games.ts` (каталог
`/game/home`) и `src/data/guide.ts` (шторка «Что здесь есть») — этот файл их не заменяет, а добавляет
техническую сторону: чем что реализовано и что можно переиспользовать.
