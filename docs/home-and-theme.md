# Главная, «О платформе» и пастельная тема

**Вид сайта** сделан по макетам владельца (`urimal_landing.html`, `urimal_korean_dashboard.html`, `new_design.html`; сами файлы лежат
у него в Downloads, папку `design/` из репозитория удалили): розово-голубой градиент, стеклянные карточки, шрифт Archivo / Noto Sans KR
(самохост, `src/assets/home/fonts.css`), вес 600–700. Он **заменил** прежний вид (вес 500, шрифт с засечками, фото уголком): это
новое решение владельца, возвращать старый не надо (он есть в истории git). Звука нет (кнопок «послушать» из макетов нет), иероглифов нет,
декоративные надписи хангылем. Название платформы **우리말** везде (меню, главная, вкладка браузера, шапка игры).

## Главная `/` (`src/views/HomeView.vue`)
Один в один по `new_design.html` («тихий» вариант): рамка-паспарту с ✦, верхняя полоса (`우리말` · ссылки **О платформе**, Словарь,
Грамматика, Памятка, Чтение · кнопка «Войти →», а если вход выполнен, «Платформа →»), вертикальная подпись «— N дней» слева,
огромный заголовок «Тихое пространство для корейского / 한국어» контуром, три «тихие» заметки справа (фраза дня «조금씩, 매일.»,
случайное слово, **случайное правило** грамматики), нижняя полоса (слов, правил, Telegram, строка со звёздочкой «* Отображается
только пройденный материал автором, новое появляется по мере изучения.» в одну строку, «made with 🌸»).
Наполнение владельца: описание «Слова, грамматика, справочник и игры…», кнопка «Продолжить →» (`/korean/home`), «что здесь есть»
(шторка), «Привет, имя!» или «Войти по токену» (в кабинет), ссылки Сегодня / Тренажёры / Игра на слова (🔒 без токена).
Правило: `randomRule` в `composables/useHome.ts` (только пройденные карточки `st: 'ok'` с примерами; клик ведёт на
`/korean/grammar?g=<id>`), другое после каждой перезагрузки. Адаптив: до 1024 px колонки в столбик, до 640 px ссылки раздела уходят
из шапки в ряд под кнопкой. Тесты: `tests/home.test.mjs`.

## «О платформе» (`/about`, `src/views/AboutView.vue`)
Слайдер: **слева скриншот страницы, справа название и описание**, кнопка «Открыть страницу →», стрелки, точки, клавиши ←/→, номер слайда
запоминается при обновлении (`usePersisted`). 19 слайдов (главная, история изменений, главная раздела, Сегодня, кабинет, слова, грамматика,
7 вкладок справочника, тренажёры, повторение, сад, игра) лежат в `src/data/about.ts`, картинки в `src/assets/about/<img>.webp`
(1280 px, около 750 КБ всего). У страниц за токеном пометка «🔒». Таймер занятий на этой странице и на главной скрыт.
**Изменил страницу или добавил новую → обнови слайд и скриншот.** Скриншоты снимают на демо-данных (пустой профиль, учебные ответы и
заметки без обложки и личных картинок): отдельный сервер (`DATA_DIR=<tmp> PORT=3002 PROGRESS_TOKEN=… node server/dist/main.js`) и
`API_PORT=3002 npx vite --port 5198`. Тест `tests/about.test.mjs` проверяет, что у каждого слайда есть картинка и живая ссылка.

## SEO (`src/data/seo.ts`, `index.html`, `public/`)
- `seo.ts`: заголовок (до 75 символов, с названием 우리말), описание (60–190) и `noindex` для каждой страницы; `applySeo` вызывается из
  `router.afterEach` и обновляет `<title>`, `description`, `robots`, `canonical`, `og:*`, `twitter:*`. Закрытые токеном страницы (`today`,
  `cabinet`, `trainers`, `review`, `garden`, `game`) не индексируются и закрыты в `robots.txt`. Неизвестный адрес получает общие данные.
- `index.html`: метатеги по умолчанию (то, что видят роботы соцсетей, не выполняющие JavaScript), canonical, Open Graph с картинкой
  `og-image.png` (1200×630, кадр главной), Twitter card, `theme-color`, манифест, JSON-LD (`WebSite` и `LearningResource`), `<noscript>`.
- `public/`: `sitemap.xml` (12 открытых адресов с датой), `robots.txt`, `manifest.webmanifest`, `icon-192/512.png`, значки вкладки. Всё из `public/`
  попадает на сайт целиком, поэтому тяжёлых файлов там быть не должно (тест проверяет: каждый меньше 600 КБ).
- **Предварительная отрисовка** (`scripts/prerender.mjs`, запускается в конце `npm run build`, браузер и новые пакеты не нужны): для каждой
  открытой страницы создаётся `dist/<адрес>/index.html` со своими `<title>`, описанием, canonical, Open Graph и **настоящим содержимым
  внутри `#app`** (весь словарь таблицей, все правила грамматики, справочники, алфавит, примеры, слайды «О платформе», ссылки на разделы).
  Данные грузит сам Vite в режиме SSR (как в тестах). Роботы Яндекса, Google, соцсетей и браузеры без JavaScript видят всё сразу; Vue при
  запуске заменяет заготовку живым приложением. Заготовка стилизована минимально (`.seo-shell` в `index.html`). Тест: `tests/prerender.test.mjs`.
  Сайт остаётся обычным Vue-приложением (не SSR и не Nuxt), это «пререндер»: данные страницы фиксируются при сборке.
- **Добавил открытую страницу** → допиши её в `seo.ts`, `public/sitemap.xml`, а в `scripts/prerender.mjs` в `NAV`, `H1` и `BODY`.
- **Яндекс**: подтверждение сайта (`<meta name="yandex-verification" …>`) лежит в `index.html` и попадает на все отрисованные страницы.
- Для отрисованных страниц Caddy должен уметь отдавать `<адрес>/index.html`: в блоке сайта `try_files {path} {path}/index.html /index.html`
  (см. `docs/hosting.md`). Без этого сайт работает, но отдаёт общий `index.html` и пререндер не используется.
- После выкладки: добавить сайт в Google Search Console и Яндекс.Вебмастер, указать `https://korean.meeymirita.ru/sitemap.xml`,
  проверить превью в отладчиках соцсетей. Обновил страницу или текст: поменяй `lastmod` в `sitemap.xml`.

## Фраза дня (`src/data/phrases.ts`)
21 фраза только из пройденного (уроки 1–11 и прошедшее время, без будущего; в переводах «я» нейтрально: «поел(а)»). После каждого

(`HOME_PHRASE` в `useHome.ts`); в «Главной раздела» блок «Фразы дня» показывает **две** разные фразы (`HOME_PHRASES`, `pickOther`), котика 🐱 убрали. Тесты: `tests/home.test.mjs`. Новую фразу просто допиши в `PHRASES`.

## Пастельная тема (`src/assets/sky.css`)
Класс `.sky` стоит на оболочке раздела (`KoreanLayout`), странице игры и окнах (`GrammarModal`: `study sky study-modal`; фон-градиент
не накладывается на окна из-за `:not(.study-modal)`). Переопределяет переменные `.study` и `.game` (`--accent` фиолетовый,
`--pink` для активного пункта, `--surface` белое стекло). Боковое меню (`KoreanLayout.vue`) — плавающая стеклянная карточка, пункты-пилюли
с иконками (`icons` там же); порядок: Главная, **Кабинет**, Сегодня, **Игра на слова** (без смайлика), Слова, Грамматика… (номера в `sections.ts`: кабинет 01, сегодня 02), внизу меню ссылки на неё нет. Карточка кабинета
с уровнем внизу меню. Строка над тренажёрами без смайликов: счётчики слева, «Старт · 0:00» и «Обновить слова» справа.
Новое окно или просмотрщик выноси в `<Teleport to="body">` и красуй своим CSS без привязки к `.study` (иначе вне `.study` стили пропадают).

## Окно поиска по платформе (`SearchWindow.vue`)
Кнопка «Поиск ⌘K» справа вверху на страницах раздела (на телефоне внизу слева) и сочетание Ctrl/⌘ + K открывают окно с тем же поиском,
что на «Главной раздела», но **результаты показываются прямо в окне, никуда не переходя**: слово раскрывается в разбор примера, фраза
справочника разворачивается целиком, предложение разбирается по словам, правило открывается окном грамматики поверх поиска. Esc или клик по
фону закрывает; запрос помнится, пока страница открыта (`composables/useSearchWindow.ts`). Данные — `data/korean/search.ts`.

## Общие окна и плашки
- **Плашки** справа вверху под кнопкой поиска (`ToastHost.vue`, `stores/toast.ts`): розово-голубые, ошибки красные, до четырёх сразу, закрываются кликом.
  `useToastStore().ok(текст)`, `.info`, `.error`. Показываются после действий и при входе/выходе и потере связи с сервером.
- **Окно подтверждения** (`ConfirmDialog.vue`, `composables/useConfirm.ts`): `await askConfirm({ title, text, ok, danger })`.
  Встроенные `confirm()`/`alert()` не использовать. `askTokenDo({ title, text, ok }, async token => …)` то же, но с полем для токена: окно само выполняет действие, пока сервер не принял токен
  (ошибка «неверный токен подтверждения» показывается внутри окна, окно не закрывается), возвращает true при успехе; `askToken` просто возвращает
  введённый токен. Для опасных действий. Слои: окно подтверждения 500, плашки 600.
- **Значок вкладки**: розовая ✳ (`public/favicon.svg`, запасные `favicon-32.png` и `apple-touch-icon.png`, подключены в `index.html`).
- **Таймер занятий** (`StudyTimer.vue`, `stores/timer.ts`): кнопка справа внизу на всех страницах, кроме главной и «О платформе»,
  только у владельца; напоминание про таймер через 15 секунд и потом раз в 10 минут.
