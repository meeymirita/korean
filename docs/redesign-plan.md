# План: весь сайт в тёмно-розовом дизайне

Образец: `urimal-landing.html` владельца (винный фон `#0b0508` / `#2a0a18`, розовое свечение за курсором, шапка-«таблетка», белые кнопки, JetBrains Mono для подписей, Archivo для заголовков, Noto Sans KR для хангыля).
Ветка: `feature/dark-pink-redesign` (от `main`). Решение владельца 2026-11-19: отходить от макета нельзя, всё держать в том же цвете.

## Что уже сделано

- Оболочка открытых страниц `src/components/site/PinkShell.vue`, токены и шрифт в `src/assets/pink.css`, своя полоса прокрутки-линия.
- Главная `/`, `/about`, `/history`, `/me`, весь `/dict*` и `/ru*`, окна «Что здесь есть» и «Запросить доступ».
- Тема «Розовая» (`wine`, по умолчанию) для раздела `/korean`: `wine.css` собирается из `dark.css` скриптом `scripts/build-wine.mjs`. Это временное решение: цвета подменены механически, а не нарисованы заново.

## Что надо сгенерировать заново

Сейчас всё нарисовано в пастельном светлом стиле на светлом фоне; на тёмном вине часть картинок будет смотреться чужой (светлая подложка, тёмные контуры).

### Иконки интерфейса (`src/assets/icons`, 44 файла `.webp`, около 770 КБ)

Рекомендация: заменить на один набор линейных SVG (`stroke="currentColor"`, 24×24, линия 1.75 px, скруглённые концы), чтобы цвет брался из темы, а весил весь набор около 20 КБ. Компонент `Icon.vue` менять не придётся: он берёт картинку по имени из `src/lib/icons.ts`, достаточно поменять пути.
Нужны имена: arrows, back, bell, bread, bulb, calendar, chart, chat, check, coin, fire, flag-kr, gear, goldstar, key, lock, moon, notebook, party, picture, puzzle, question, search, sprout, stopwatch, sun, target, user, wrench.
Вариант «рисованные»: оставить webp, но перегенерировать на прозрачном фоне в розово-белом стиле (512×512, прозрачный фон, без тёмного контура).

## Правила работы

- Один этап, затем показ владельцу, потом следующий; смотреть на странице владельца, мои скриншоты в этой среде не снимаются.
- Старые правила для светлых страниц в `dark.css` убирай вместе со страницей (так чёрный прямоугольник на «О платформе» и получился: старые `.about` и `.hist` красили новые блоки).
- Классы страниц не должны совпадать с классами из глобального CSS (`.open`, `.card`, `.btn`, `.dot`): проверять `grep` по `assets/*.css`.
