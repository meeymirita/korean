# Приложение 우리말 для Mac

Личная оболочка Electron вокруг боевого сайта `https://korean.meeymirita.ru`. Только для себя: ничего не публикуется, подпись «ad-hoc», платная учётка Apple не нужна. Сайт обновляется сам (выкладка по обычному порядку), оболочку пересобирать нужно редко (новая версия Electron, значок).

## Что делает

- Одно окно без адресной строки, помнит размер и положение (`window.json` в папке данных приложения), второй запуск поднимает первое окно.
- Вход по токену хранится в постоянном хранилище окна (`partition: persist:urimal`): входить один раз.
- Свой адрес остаётся в окне, чужие ссылки (`t.me` и т. п.) открываются в обычном браузере (`setWindowOpenHandler`, `will-navigate`).
- Нет связи с сайтом: страница `offline.html` с кнопкой «Повторить» (сама повторяет и при появлении сети).
- Меню и сочетания Mac: ⌘Q, ⌘W, ⌘R (обновить), ⌘+ / ⌘− / ⌘0 (масштаб), полный экран, инструменты разработчика в меню «Вид». ⌘K, «/», F, Esc остаются сайту.
- Значок ✳ (из `frontend/public/icon-512.png`). Dock-счётчик «пора повторить»: раз в 5 минут и после каждой загрузки страницы оболочка читает число слов из самого сайта (`$pinia.state.progress.data.words`, формула `data/review.ts`: интервалы 0/1/3/7/14/30 дней). Токены оболочка не трогает и в файлы не пишет. Оценка чуть выше точной: слова, которых уже нет в словаре, не отсеиваются.
- Микрофон для голосового собеседника: `NSMicrophoneUsageDescription` в `Info.plist`, запрос macOS при первом запуске; разрешения окна только микрофон, буфер, полноэкранный режим и уведомления, и только для своего сайта.
- Безопасность: `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`; единственное, что страница просит у оболочки, это `retry` на странице «нет сети» (`preload.js`).

## Сборка и установка (только на своём Mac, Apple Silicon)

```
npm --prefix desktop install
npm --prefix desktop run build          # desktop/dist/우리말-darwin-arm64/우리말.app
npm --prefix desktop run install-app    # копия в /Applications
```

Пакеты: `electron` и `@electron/packager` (без `electron-builder`, без публикации и автообновлений). Значок `.icns` собирается из PNG через `sips` и `iconutil` при первой сборке. `dist/`, `node_modules/` и `icon.icns` в git не попадают. Другой адрес сайта для проверки: переменная `URIMAL_SITE` при запуске (`URIMAL_SITE=http://localhost:5198 …/MacOS/우리말`).

Приложение подписано ad-hoc (`codesign -s -`): `spctl` скажет «rejected», но собранное и запущенное на этом же Mac оно открывается без предупреждения. Если macOS всё же ругается, один раз: правый клик по приложению → «Открыть».

## Что проверено и что нет

Проверено 2026-11-20 на сборке: запуск, загрузка сайта в окно, вход (токен демо-сервера) и чтение числа «пора повторить» из хранилища сайта, внешняя ссылка не открывается в окне, страница «нет сети» при недоступном сайте, значок в `Info.plist`, подпись.
Не проверено (нужен человек за экраном): вход на боевом сайте и двухфакторный вход, голос с микрофоном и запрос разрешения macOS, воспроизведение видео AV1 и музыки при фоновой работе и мультимедиа-клавиши, загрузка картинок и копий через системное окно выбора файла, PDF-отчёт, перо, вид счётчика на значке в Dock.
