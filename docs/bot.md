# Бот-игрок

Проверяет, что все режимы игры «Хлебушек» работают без ошибок: сам проходит каждый режим на каждом чипе уровня и ищет сбои. Два уровня, оба берут список режимов и чипов из кода (`MODES`, `STORY_MODES`, `LEVEL_LABELS` в `src/game/`), а не из своей копии: новый режим или чип попадает в прогон сам.

## Уровень A: задания без браузера (быстро, в CI)

Файлы: `frontend/test/bot-lib.ts` (состояние, зерно, проверки одного задания), `bot-gen.spec.ts` (каждый режим × чип, 120 заданий на клетку), `bot-gen-variety.spec.ts` (разнообразие потока, 1000 заданий на режим).

```
cd frontend
npx vitest run test/bot-gen.spec.ts --maxWorkers=1
npx vitest run test/bot-gen-variety.spec.ts --maxWorkers=1
BOT_SEED=123 BOT_N=2000 npx vitest run test/bot-gen.spec.ts --maxWorkers=1   # другое зерно, больше заданий
BOT_REPORT=/tmp/rep.md npx vitest run test/bot-gen-variety.spec.ts           # дописать «чего не хватает в данных»
```

Проверяется в каждом задании: нет `undefined` / `NaN` / `[object Object]`, нет японских и китайских знаков, варианты не повторяются, верный на месте и совпадает с `right`, у текста размер по чипу (2–4, 5–10, 8–12; у `spot` 2–3 и 4–5; у `expert` ровно 5 / 10 / 15 пропусков), верный ответ каждого пропуска есть в банке, одинаковых предложений в тексте нет, частица стоит по 받침, нет запретов из `/api/public/rules` (`checkSentence`), нет двойника верного ответа (은/이, 는/가, 뭐/무엇). Отдельно: четыре сложности «Собери предложение», все семьи «Текстов по правилу», времена, наборы слов.

Разнообразие (`bot-gen-variety.spec.ts`): один и тот же верный ответ в любых 10 подряд не чаще потолка (зависит от числа разных ответов режима), доля самого частого ответа, повтор того же задания в окне 30 (если в режиме 60+ разных заданий), место верного варианта. Сам генератор в `generators.ts` следит за этим при выдаче (`recent`, `sameCap`, `genQuestion`): тот же ключ не ближе 60% набора, тот же ответ не чаще `sameCap()` раз из 10.

Режимы, где разных заданий мало (повторы в окне 30 неизбежны), тест печатает в `BOT_REPORT`: сколько заданий и что добавить. Слова и предложения в словарь добавляет владелец. Известные нехватки данных лежат в `KNOWN` в `bot-gen.spec.ts` (сейчас «Уровень вежливости»: 4 формы «спасибо», а чип «Длинный 5–10» просит 5–10 разных предложений).

## Уровень B: бот в браузере

`scripts/play-bot.mjs`: Chromium без окна из кэша Playwright, протокол браузера по WebSocket (Node 24+, новых пакетов нет). Нужен сайт с крючком `window.__gameProbe`: он включается `NUXT_PUBLIC_TEST_HOOKS=1` (`runtimeConfig.public.testHooks`, `GameHooks.probe`), в боевой сборке его нет. Через крючок бот читает текущее задание (верный ответ) и счётчики, список режимов и чипов берёт из `__gameProbe.modes()`.

```
NUXT_PUBLIC_TEST_HOOKS=1 bash scripts/local-demo.sh          # сайт 5198, сервер 3011, токен local-demo-token-2026
TOKEN=local-demo-token-2026 node scripts/play-bot.mjs         # светлая тема, 1440×900, владелец
THEME=wine SIZE=phone TOKEN=… node scripts/play-bot.mjs       # «Розовая», телефон 390×800 с касаниями
GUEST=1 TOKEN=… node scripts/play-bot.mjs                     # гость: бот выписывает гостевой токен на час и отзывает его
MECHANICS=1 MODES=word,part TOKEN=… node scripts/play-bot.mjs # блиц (30 с), выживание, 50/50, «Обновить вопрос», перезагрузка
```

Переменные: `BASE`, `TOKEN` (только демо-сервера, не боевой), `THEME` (`light`, `wine`), `SIZE` (`desktop`, `phone`), `GUEST`, `MODES`, `STEPS` (заданий на клетку, 10), `STRATEGY` (`right`, `wrong`, `mix70`, `random`, `keys`, `drag`, по умолчанию `all`: стратегии идут по кругу по клеткам), `MECHANICS`, `OUT` (папка отчёта), `SHOTS=1` (скриншот на каждое нарушение), `DEBUG=1`.

После каждого ответа: разбор показан, верный вариант подсвечен ровно один, счётчики игры = экрану = ожидаемому (верно + неверно, серия сбрасывается), нет ошибок консоли, исключений, ответов 4xx/5xx и упавших запросов (допустимое в `scripts/play-bot-allow.json`, каждая запись с причиной), нет горизонтальной прокрутки, обрезанного текста, кнопок без подписи, незагруженных картинок, карточки «?» в «Как собрано». Чип нажимается, выбор запоминается и переживает перезагрузку; размер текста совпадает с названием чипа. Время отрисовки следующего задания: среднее не больше 100 мс. В «Розовой» ищется зелёное, синее и фиолетовое. Гость не пишет на сервер.

Контраст текста ниже 4,5:1 бот печатает как **предупреждение** (раздел «Предупреждения» отчёта), код выхода не меняет: оформление владельца, решать ему. На 2026-11-20 в светлой теме: белое на розовом у кнопок «Проверить» и «Дальше →» (3,33), подписи заданий и «?» (4,19), «Разбор» у текстов (3,0–3,8).

Отчёт: `OUT/report-<тема>-<экран>[-guest].md|json|html`: таблица «режим × подрежим» (пустая клетка = ошибка), нарушения по видам, подробно с ключом задания. Код выхода 1, если нарушения есть. Один браузер, всё по очереди; полный прогон светлой темы на 89 клетках по 6 заданий около 2,5 минут.

## Тренажёры (`TaskSession`)

Уровень A: `frontend/test/bot-tasks.spec.ts` собирает наборы заданий всех тренажёров (`randomTasks`, «5 минут», «Похожие, но разные», перевод во всех направлениях и уровнях, «Переведи и объясни», чтение, сценки, часть речи, знаки, каждый набор «Частиц», «Потренировать правило» для каждой карточки с тремя и больше примерами и смесь правил) и проверяет: варианты разные, ответ среди них, нет мусора и иероглифов, слова только из `STUDY`, нет запретов из `/api/public/rules`, в серии правила не меньше 8 разных вопросов.
Уровень B: бот берёт id тренажёров из каталога страницы игр (ссылки `?game=`), открывает каждый и по крючку `window.__taskProbe` (`TaskSession.vue`, тоже только при `NUXT_PUBLIC_TEST_HOOKS=1`) проходит серию теми же стратегиями; проверяет один подсвеченный верный вариант, зачёт верных и неверных ответов, итог «N из M». Экраны без серии (`match`, `syllables`, `keyboard`) бот только открывает и проверяет вёрстку и консоль.

## Что бот не проверяет

Чат-помощника и голос (внешние сервисы), вид на iPad и перо, боевой сервер. «Сегодня», «Повторение», «Итоговая оценка» и «Мои ошибки» бот не обходит: у них свои экраны.
