## 2026-10-30 (правки по замечаниям владельца, третий заход)

- **У картинок заметок, обложки и раздела «Картинки» теперь отдельные списки.** У картинки есть назначение `kind`: `gallery`
  («Картинки»), `note` (вложение заметки), `cover` (обложка кабинета). `GET /api/images` по умолчанию отдаёт только `gallery`
  (`?kind=note|cover` — другие), загрузка принимает поле `kind`, место считается по всем. Картинка заметки или обложки, которой
  никто не пользуется, удаляется (с файлом и миниатюрой) при сохранении заметок или профиля, но не раньше чем через сутки
  (`pruneImages`). Старые базы: столбец `images.kind` добавляется сам, картинки из заметок и обложка помечаются по назначению.
- **Встроенные окна браузера (`confirm`) заменены своим окном** (`ConfirmDialog.vue`, `composables/useConfirm.ts`: `askConfirm`
  возвращает промис true/false, Esc и клик по фону — «нет», у опасных действий фокус на «Отмена»): удаление заметки и картинки,
  отзыв гостевого доступа, сброс прогресса, сброс статистики игры. Новые подтверждения делай через `askConfirm`, не через `confirm()`.

## Чек-лист: обновить сайт на сервере
Сервер заменён целиком (NestJS + SQLite), поэтому порядок такой (подробности в `docs/hosting.md`):
1. `node -v`: нужен Node 22.18+ или 24.12+ (если меньше, сначала обновить Node)
2. `cd /var/sites/korean && git pull`
3. `npm run build` и `cd server && npm ci && npm run build && cd ..`
4. В `/etc/systemd/system/progress.service` заменить `ExecStart` на `/usr/bin/node server/dist/main.js`, затем `systemctl daemon-reload && systemctl restart progress`
5. `curl http://127.0.0.1:3001/api/health` (ответ `{"ok":true}`), в кабинете открыть «Картинки» и «База»
5. Проверка гостя: в кабинете создать гостевой токен на 1 час, открыть ссылку в окне инкогнито, убедиться, что закрытые разделы
   открыты; отозвать токен и обновить страницу (снова закрыто).
Новых переменных окружения нет, `server/.env` остаётся прежним. База `server/data/app.db` создастся сама; старые `progress.json`, `guests.json`, `notes.json` больше не нужны.
