## 2026-11-02: Nuxt, `backend/` + `frontend/`, боевой сервер переведён
- Сайт переехал с Vue SPA на **Nuxt 4 с отрисовкой на сервере**; сервер обновлён до NestJS 12. Репозиторий разделён: `server/` → `backend/`, сайт → `frontend/`; `tests/`, `docs/`, `scripts/`, `.github/` остались в корне.
- Ветка `nuxt` стала `main` (fast-forward), прежняя версия сохранена как `main_old`. CI, `deploy.sh` (отдельный `npm ci` для `frontend/`, откат пересобирает сайт), `demo-seed.mjs`, документация переведены на новые пути.
- Тесты фреймворков: Nest (`backend/test`, vitest + `@nestjs/testing` + supertest; jest не запускается с ESM-пакетами Nest 12) и Nuxt (`frontend/test`, `@nuxt/test-utils`); `npm test` запускает всё (519 + 8 + 9).
- Боевой сервер: службы `korean-web` (3000) и `progress` (`backend/dist/main.js`, 3001), Caddy проксирует на обе, `.env` и данные перенесены в `backend/`. Проверено владельцем (главная, вход, «Сегодня», кабинет, видео, `robots.txt`, `sitemap.xml`, картинки), `deploy.sh` отвечает «Нечего обновлять».
- Раньше в тот же день: массовая загрузка картинок `/upload`, `/api/health` с проверкой базы, Swagger (`SWAGGER=1`), `scripts/check-links.mjs`, блокнот на iPad (рисует только перо, ластик стирает кусок штриха), письмо-подборка по времени, «Частицы и окончания».
