**Сервер переписан на NestJS + SQLite** (`docs/server.md`): весь прогресс (ответы, слова, дни, профиль, настройки), заметки, гостевые токены,
журнал событий и картинки в базе `server/data/app.db`; данные с чистого листа, старые JSON не переносились. Сайт отправляет
действия очередью, сервер главный. Новые вкладки кабинета: «Картинки» (загрузка, галерея, до 50 МБ каждая и 500 МБ всего) и «База»

Сервер разбит на модули (`index`, `config`, `http`, `storage`, `guests`).

## Чек-лист: обновить сайт на сервере
Сервер заменён целиком (NestJS + SQLite), поэтому порядок такой (подробности в `docs/hosting.md`):
1. `node -v`: нужен Node 22.18+ или 24.12+ (если меньше, сначала обновить Node)
2. `cd /var/sites/korean && git pull`
3. `npm run build` и `cd server && npm ci && npm run build && cd ..`
4. В `/etc/systemd/system/progress.service` заменить `ExecStart` на `/usr/bin/node server/dist/main.js`, затем `systemctl daemon-reload && systemctl restart progress`
5. `curl http://127.0.0.1:3001/api/health` (ответ `{"ok":true}`), в кабинете открыть «Картинки» и «База»
5. Проверка гостя: в кабинете создать гостевой токен на 1 час, открыть ссылку в окне инкогнито, убедиться, что закрытые разделы
   открыты; отозвать токен и обновить страницу (снова закрыто).
Новых переменных окружения нет, `server/.env` остаётся прежним. База `server/data/app.db` создастся сама; старые `progress.json`, `guests.json`, `notes.json` больше не нужны.
