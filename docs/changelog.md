Сервер разбит на модули (`index`, `config`, `http`, `storage`, `guests`).

**Тесты** (`npm test`, 101 штука, около 3 секунд, без зависимостей): хранилище прогресса, повторение, разбор предложений, гостевой

## Чек-лист: обновить сайт на сервере
Менялся `server/` (модули, гостевые токены, заметки), поэтому после `git pull` сервер прогресса нужно перезапустить:
1. `cd /var/sites/korean && git pull`
2. `npm run build`
3. `systemctl restart progress`
4. `curl http://127.0.0.1:3001/api/health` (ответ `{"ok":true}`)
5. Проверка гостя: в кабинете создать гостевой токен на 1 час, открыть ссылку в окне инкогнито, убедиться, что закрытые разделы
   открыты; отозвать токен и обновить страницу (снова закрыто).
Новых переменных окружения нет, `server/.env` остаётся прежним. Файлы `server/data/guests.json` и `notes.json` создадутся сами.
