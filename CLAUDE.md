## Строгий порядок работы (для любой модели, читать первым)

**Перед правкой**
1. Прочитай этот файл целиком, потом документ по теме из таблицы «Документация» и сами файлы, которые будешь менять. Не правь файл, который не открыл в этом разговоре.

4. Ответ владельца на вопрос стоит **перед** вставленным текстом вопроса, а не после («да» над цитатой вопроса относится к этой цитате). Короткое «делай», «давай» относится ко всему перечисленному. Если понять нельзя, задай один вопрос и продолжай остальное.

**Как править**
5. Маленькими точными заменами. Для текста на русском пиши скрипт Python в файл во временной папке (не в репозитории) с проверкой `assert s.count(старое) == 1` перед каждой заменой и запускай его: так замена не попадёт не туда и не сработает наполовину. Большие файлы целиком не переписывай.
6. `frontend/src/game/engine.ts` с 2026-11-11 проверяется компилятором (типы вопроса, состояния и хуков в `src/game/types.ts`): `@ts-nocheck` и `any` в него не возвращай, новое поле вопроса сначала допиши в `Question`. После любой правки в нём всё равно гоняй игровые тесты (пункт 9): файл большой, с общим состоянием.
7. Одно действие, один коммит. Не складывай разные задачи в один коммит и не трогай лишнего «заодно», кроме явной ошибки рядом (её чини и назови в ответе).
8. После правки обнови: описание в `docs/` (или `docs/trainers/<режим>.md`), запись в начало `HISTORY`, сгенерированные файлы (скрипты перечислены в «Правилах кода»), локальный `plan-and-fixes/plan-new.md` (сделанное удалить, новое дописать).

**Проверка (ноутбук владельца слабый: одна тяжёлая команда за раз, ничего не запускать параллельно)**

## Правила кода

- Запросы к серверу только через `fetchT` (`src/lib/http.ts`, таймаут 15 с, файлы 120 с), не через голый `fetch`; заголовок `Authorization: Bearer ${progress.bearer}` (не `progress.token`).
  При отрисовке на сервере: `useFetch` с `baseURL: runtimeConfig.apiBase` и `timeout` (пример `PublicMeView.vue`).
- Подтверждения только `askConfirm`; **опасные действия только `askTokenDo(опции, действие)`** (повторный ввод токена, заголовок `X-Confirm-Token`, проверяет сервер).
- Результат действий показывай плашкой `useToastStore().ok/.error`.
- Состояние страницы, которое должно переживать обновление: `usePersisted` (sessionStorage) или `?параметр` в адресе (`useQueryParam`).
- Окна и просмотрщики с `position: fixed` выноси в `<Teleport to="body">`. Слои: подтверждение 500, плашки 600, просмотр картинки 300, окно заметки 60, окно грамматики 50, поиск 45.
- **Код выполняется и на сервере (Nuxt SSR):** в модуле и в `setup` открытых страниц нельзя трогать `window`, `document`, `localStorage`, `matchMedia`
  (только в `onMounted`, обработчиках или под `import.meta.client`). Переменная модуля на сервере общая для всех посетителей: состояние запроса в `useState`.
  Случайное на открытых страницах только от зерна (`useHomePicks`, `withSeed` из `lib/seeded.ts`), иначе «Hydration mismatch». Вход и прогресс из `localStorage` подставляются после оживления (`plugins/app.client.ts`).
- Сочетания клавиш: заняты ⌘/Ctrl+K и «/» (поиск), F (меню), Esc, 1–4 и Enter в заданиях. Новую клавишу сначала допиши в `src/lib/shortcuts.ts`.
- ✳ пиши с селектором `U+FE0E` (`✳︎`), иначе iOS рисует зелёный смайлик. `KNOWN_STREAK` живёт в `stores/progress.ts` и `backend/src/progress/progress.service.ts`: менять в обоих.

## Порядок работы с материалами (так договорились с владельцем, 2026-11-04)

Тему и порядок задаёт только Лера (даёт грамматику на неделю, закрепляет на субботнем уроке): без неё сам ничего не добавляй и не предлагай новых тем.
Владелец разбирает тему сам в **десктопном приложении Claude** (другой чат, не этот): оттуда PDF с объяснением, задания, списки слов; он печатает и вклеивает в тетрадь.
**Учебник и файлы Леры** лежат в локальной `материалы/учебник/` (снимки Miro по темам в `miro/`, PDF Леры в `от-Леры/`; что где и чего не хватает: `материалы/учебник/ИНДЕКС.md`). Слова и имена из них вносятся на сайт только по слову владельца.
Сюда это попадает так:
1. Владелец кладёт файлы из десктопного приложения в локальную `материалы/ГГГГ-ММ-ДД/` (не в git; только файлы оттуда, `ЗАДАНИЕ.md` и картинок там больше нет). Слова в папку не кладёт: записывает на сайте (кнопка «Добавить слово») и присылает токен.
2. Говорит одной фразой: «карточки из материалы/…»; для слов присылает токен из шторки «Новые слова».
3. Ты читаешь PDF и **дополняешь** карточку на сайте (`grammar.ts`), а не переписываешь: что на сайте уже есть, оставляй, добавляй недостающее (ошибки, сравнения, порядок слов). Новая карточка идёт во «Мои карточки» (без `l`) со `st: 'soon'`. Статус `ok` ставь **только по слову владельца** («отметь пройденной»); он относится к вкладке «Мои карточки».
4. После смены статуса или словаря: `node scripts/chat-curriculum.mjs`, `node scripts/digest-pool.mjs`, `node scripts/build-study-data.mjs`, при новых словах ещё `node scripts/build-words-json.mjs`; тесты, коммит, пуш, напомнить про деплой.
Десктопное приложение сверяет новые слова на дубли по публичному `https://korean.meeymirita.ru/words.json` (после деплоя, кэш до ~15 минут). Пройденная грамматика и все предложения открыты для чтения: `/api/public/grammar`, `/api/public/sentences`. Таблица ошибок из тетради на сайт не вносится.

## Стек и запуск

Папки: `frontend/` (Nuxt 4, SSR, Vue 3, Pinia, `srcDir: 'src'`), `backend/` (NestJS 12 + Prisma + PostgreSQL, Node 22.18+ или 24.12+), `docker/` (Dockerfile, Caddyfile, Prometheus, Grafana), в корне `tests/`, `docs/`, `scripts/`, `.github/` и `package.json` только для тестов
(три отдельных `node_modules`; корневой нужен тестам, `scripts/link-test-deps.mjs` делает `vue` и `pinia` ссылками на копии из `frontend/`). **Пути `src/...` везде считай от `frontend/`.**

- Установка: `npm ci && npm --prefix frontend ci && npm --prefix backend ci && npm --prefix backend run db:generate` (Prisma Client; тестам нужны PostgreSQL, Redis, Meilisearch и `pg_dump` 17+: как поднять, в `docs/docker.md`, последний раздел).
- Из корня: `npm run dev` (сайт, порт 3000, `/api` → `API_PORT`), `npm run server:dev` (API, порт 3001), `npm run build`, `npm run type-check`, `npm test`.
- Хостинг: Docker Compose (`docker-compose.yml`): сайт `127.0.0.1:3000`, API `127.0.0.1:3001`, PostgreSQL, Redis, Meilisearch, Prometheus, Grafana; боевой Caddy сервера остаётся прежним и ходит на эти порты. Обновление: `bash scripts/deploy.sh` (копия базы, сборка, откат сам). Перенос данных, копии, мониторинг: `docs/docker.md`; Caddy, защита, диагностика: `docs/hosting.md`.

## Как проверять

- CI на GitHub (типы, сборка, тесты, `npm audit`, на Node 22 как в образах Docker и на Node 24 как на ноутбуке владельца) идёт на каждый push; Dependabot раз в неделю предлагает обновления (крупные не сливать вслепую).
- Тесты: `npm test` (сборка сервера, Nest-тесты `backend/test`, Nuxt-тесты `frontend/test`, затем `tests/*.test.mjs`). Отдельно `npm run test:nest`, `npm run test:nuxt`.
  **Игровые тесты `frontend/test` разнесены по файлам** (`game.spec.ts`, `game-stories.spec.ts`, `game-variants.spec.ts`): один большой файл упирается в память Node (процесс падает с `SIGABRT`). Новые игровые тесты клади в отдельный файл.
- Покрытие (без порога, только цифры): `npm --prefix backend run test:coverage`, `npm --prefix frontend run test:coverage` (`@vitest/coverage-v8`; полный прогон тяжёлый, на ноутбуке запускай с одним файлом: `npx vitest run test/<файл>.spec.ts --coverage --coverage.include=src`).
- Линтер: `npm run lint` (`oxlint` с типами, настройки `.oxlintrc.json`; ловит забытый `await` и неиспользуемое, идёт в CI). После `npm install` в корне, если тесты не находят `pinia` или `vue`: `node scripts/link-test-deps.mjs`.
- Типы и сборка: `npm run type-check`, `npm run build`. Тест TS-модулей без браузера: `tests/_load.mjs` (`load('/src/...')`).
- Визуально: headless Chromium из кэша Playwright (`~/Library/Caches/ms-playwright/chromium_headless_shell-*/…/chrome-headless-shell`), `--screenshot` или `--remote-debugging-port`.
- Демо-сервер: `DATA_DIR=<tmp> PORT=3002 PROGRESS_TOKEN=… node backend/dist/main.js`, сайт `API_PORT=3002 npx --prefix frontend nuxt dev --port 5198`,
  данные `API=http://127.0.0.1:3002 TOKEN=… node scripts/demo-seed.mjs`. Скриншоты «О платформе» снимай только на демо-данных. Потом убери сервер и файлы.
- Вёрстка на телефоне: `TOKEN=… WIDTHS=320,390,768 node scripts/check-layout.mjs` (ничего не печатает, если всё в порядке); битые ссылки: `node scripts/check-links.mjs` (`BASE`, `TOKEN`, `EXTERNAL=1`).
- Swagger: `SWAGGER=1 npm run server` → `http://127.0.0.1:3001/api/docs` (только локально).
- На macOS нет `timeout` и `tac`; `sleep` в foreground блокируется: ждать через Monitor.
