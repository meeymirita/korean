# Контекст проекта для Claude (прочитай целиком перед работой)

Платформа **우리말** для изучения корейского: `https://korean.meeymirita.ru`. Игра на слова внутри неё называется «Хлебушек».
Репозиторий `github.com/meeymirita/korean`, ветка `main` (прежний Vue SPA хранится в `main_old`), локально `/Users/mira/Documents/projects/git_korean`.
Общение с владельцем по-русски. Главная `meeymirita.ru` это другой проект (`github.com/meeymirita/me`).

**Состояние:** платформа готова и работает на боевом сервере (Nuxt SSR + NestJS + PostgreSQL, всё в Docker Compose, `docs/docker.md`). Переделок архитектуры и дизайна не планируется:
дальше только расширение (новые слова, уроки, режимы, страницы). Стек не менять без причины.

## Владелец и как с ним работать

- Учит корейский с нуля (курс 서울대 한국어+ 1A + видеокурс 양쌤, уроки 1–30; учитель Лера, созвоны по субботам). Новые слова пишет в локальный `материалы/новые-слова/НОВЫЕ.md` (не в git): по просьбе «разнеси слова» добавь их на сайт и перенеси строки в «Внесено». Notion как словарь не ведётся (с 2026-11-04), источник правды сайт.
  Слова и заметки, которые владелец записывает на сайте (кнопка «Добавить слово» на странице «Слова»), лежат в таблице `new_words`, **берутся только через API**: владелец нажимает «Создать токен» в шторке «Новые слова» (токен на 10 минут, только чтение) и присылает его в чат, дальше `INBOX_TOKEN=<токен> BASE=https://korean.meeymirita.ru node scripts/inbox.mjs`; токен не записывать в файлы и репозиторий; в словарь переношу по его слову, заметки читаю и разбираю с ним (`docs/data.md`).
- Пишет о себе в мужском роде, но **не угадывай пол**: без родовых форм о нём («напиши», «получилось»); в русских переводах для «я» нейтрально («ходил(а)»).
- **Не забегать вперёд пройденного:** пройдены уроки 1–11 и прошедшее время (разрешено везде). Будущее время (`-ㄹ 거예요`) НЕ проходили: не использовать в заданиях
  (в «Сегодня» и тренажёры попадают только карточки со `st: 'ok'`). Карточка урока 11 («와 / 과») и уроков 12–30 пока пустые, ждём конспекты.
- Тон: просто, без лишней теории, любит интерактив «как в игре». Отвечать коротко: что сделано, что проверено, что осталось.
- Работа: показывает правки по одной и быстро меняет решение, поэтому маленькие шаги и скриншот результата. Временные файлы и скриншоты держи вне репозитория и удаляй.
  Выкладка автоматическая: пуш в `main` → CI → при зелёном CI сам идёт Deploy на сервер (`docs/docker.md`, «Обновление»); владелец проверяет результат на сайте.
- Коммиты и пуш делать можно без вопросов, отдельным коммитом на каждое действие. Сообщения на английском, повелительное наклонение,
  в конце `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. После пуша сказать, что выкладка пойдёт сама после зелёного CI; руками на сервере нужно только то, чего нет в git (правка `.env` и `docker compose up -d`).
- **Список правок и порядок работы** ведёт владелец сам; папки `правки/` больше нет (удалена 2026-11-04). Открытое смотри в «Что осталось» ниже и в `материалы/ПЛАН.md`. Новую просьбу владельца делай по одному пункту, сделанное отмечай в ответе.

  Видео не закрыты токеном, формат AV1 оставлен как есть, автора курса (Учитель Ян, `@koreanteacherYang`) указывать на странице грамматики и под видео.
- Поиск не показывать на самой главной `/`; ссылки «← На главную» в боковом меню нет; результат ответа в игре не закрывается сам.

## Правила кода

- Запросы к серверу только через `fetchT` (`src/lib/http.ts`, таймаут 15 с, файлы 120 с), не через голый `fetch`; заголовок `Authorization: Bearer ${progress.bearer}` (не `progress.token`).
  При отрисовке на сервере: `useFetch` с `baseURL: runtimeConfig.apiBase` и `timeout` (пример `PublicMeView.vue`).
- Подтверждения только `askConfirm`; **опасные действия только `askTokenDo(опции, действие)`** (повторный ввод токена, заголовок `X-Confirm-Token`, проверяет сервер).
- Результат действий показывай плашкой `useToastStore().ok/.error`.
- Состояние страницы, которое должно переживать обновление: `usePersisted` (sessionStorage) или `?параметр` в адресе (`useQueryParam`).
- Окна и просмотрщики с `position: fixed` выноси в `<Teleport to="body">`. Слои: подтверждение 500, плашки 600, просмотр картинки 300, окно заметки 60, окно грамматики 50, поиск 45.
- **Код выполняется и на сервере (Nuxt SSR):** в модуле и в `setup` открытых страниц нельзя трогать `window`, `document`, `localStorage`, `matchMedia`
  (только в `onMounted`, обработчиках или под `import.meta.client`). Переменная модуля на сервере общая для всех посетителей: состояние запроса в `useState`.
  Случайное на открытых страницах только от зерна (`useHomePicks`, `withSeed` из `lib/seeded.ts`), иначе «Hydration mismatch». Вход и прогресс из `localStorage` подставляются после оживления (`plugins/app.client.ts`).
- Сочетания клавиш: заняты ⌘/Ctrl+K и «/» (поиск), F (меню), Esc, 1–4 и Enter в заданиях. Новую клавишу сначала допиши в `src/lib/shortcuts.ts`.
- ✳ пиши с селектором `U+FE0E` (`✳︎`), иначе iOS рисует зелёный смайлик. `KNOWN_STREAK` живёт в `stores/progress.ts` и `backend/src/progress/progress.service.ts`: менять в обоих.
- Новый режим игры добавляй в `MODES` и `MODE_HELP` (`src/game/engine.ts`, тест следит).
- **Перед новым режимом игры/тренажёром сначала прочитай `docs/games-catalog.md`** (что уже есть, чем реализовано, что переиспользовать вместо дублирования); сделал новый режим или изменил — обнови каталог.
- **Любая правка тренажёра или режима (решение владельца, 2026-11-08):** просьба «добавь/измени что-то в режиме X» начинается с чтения `docs/trainers/<режим>.md` и всех файлов режима из его раздела «Файлы» (экран, данные, `lib`), потом правка, потом обновить это описание.
  **Слова в словарь сам не добавляй:** не хватает слов для заданий, примеров или разбора, скажи владельцу, что именно нужно и зачем, и реши вместе (он обычно отвечает «добавляй»); не отключай из-за этого фичу молча.
  Описание расходится с кодом: верь коду и поправь описание. Нашёл ошибку или дубль при чтении: чини сразу (общее выноси в одно место, не копируй). Новый тренажёр: свой файл в `docs/trainers/` по шаблону из `docs/trainers/README.md`.
- Предметы магазина получает сам любой новый режим на `TaskSession.vue`; цены и условия менять только в `backend/src/progress/coins.ts` и `COINS` (сайт держит копию в `src/data/coins.ts`, `shop.ts`), потом перезапустить сервер.
- **Новая страница** = файл в `src/pages/` (закрытая токеном: `definePageMeta({ private: true })`) + запись в `src/data/seo.ts` (заголовок до 75 знаков, описание 60–190, закрытая `noindex`)
  + пункт в `src/data/korean/crumbs.ts` (хлебные крошки) + в шторку «Что здесь есть» (`src/data/guide.ts`). Sitemap и robots Nuxt строит сам по `seo.ts`. Тег `yandex-verification` в `nuxt.config.ts` не удалять.
- Заметное изменение: запись в начало `HISTORY` (`src/data/history.ts`, тест следит за форматом). Изменил страницу: обнови слайд и скриншот в «О платформе» (`src/data/about.ts`, `src/assets/about/`)
  (README без скриншотов; число слов и правил в нём сверяет `tests/readme.test.mjs`).
- Менял `dark.css`: `node scripts/build-night.mjs` (собирает `night.css`, тест следит).
- Менял словарь или `translations.ts`: `node scripts/digest-pool.mjs` и `node scripts/build-words-json.mjs` (публичный `/words.json` для сверки на дубли); менял словарь или пройденные темы: `node scripts/chat-curriculum.mjs`. Тесты следят.
- Поменял сервер: пересобери и перезапусти локальный (`npm run server:build`, затем `pkill -f "node dist/main.js"; npm run server`; в Docker `docker compose up -d --build backend`), иначе сайт «не видит» новых возможностей. Всё, что вызывает async-методы сервера (в том числе проверки `confirm.require`), обязательно с `await`: без него защита молча не срабатывает.

Выделенная в редакторе строка `.env` тоже уходит в переписку: если там секрет, не повторять и не записывать, попросить перевыпустить.
- **Telegram (`docs/telegram.md`):** новый вид уведомления = `topic` в `TG_TOPICS` (`templates.ts`), номер темы `TELEGRAM_TOPIC_*` в `.env.example` и `docker-compose.yml`, баннер `tg-<тема>.png` в `frontend/public/tg`; заменил баннеры: подними `BANNER_VERSION` в `notify.service.ts` (Telegram кэширует картинки по адресу). Очистка тем только с повторным токеном (`ConfirmService.require`, обязательно с `await`).

## Порядок работы с материалами (так договорились с владельцем, 2026-11-04)

Тему и порядок задаёт только Лера (даёт грамматику на неделю, закрепляет на субботнем уроке): без неё сам ничего не добавляй и не предлагай новых тем.
Владелец разбирает тему сам в **десктопном приложении Claude** (другой чат, не этот): оттуда PDF с объяснением, задания, списки слов; он печатает и вклеивает в тетрадь.
Сюда это попадает так:
1. Владелец кладёт файлы из десктопного приложения в локальную `материалы/ГГГГ-ММ-ДД/` (не в git; только файлы оттуда, `ЗАДАНИЕ.md` и картинок там больше нет). Слова кладёт в `материалы/новые-слова/НОВЫЕ.md`.
2. Говорит одной фразой: «разнеси слова» или «карточки из материалы/…».
3. Ты читаешь PDF и **дополняешь** карточку на сайте (`grammar.ts`), а не переписываешь: что на сайте уже есть, оставляй, добавляй недостающее (ошибки, сравнения, порядок слов). Новая карточка идёт во «Мои карточки» (без `l`) со `st: 'soon'`. Статус `ok` ставь **только по слову владельца** («отметь пройденной»); он относится к вкладке «Мои карточки».
4. После смены статуса или словаря: `node scripts/chat-curriculum.mjs`, `node scripts/digest-pool.mjs`, при новых словах ещё `node scripts/build-words-json.mjs`; тесты, коммит, пуш, напомнить про деплой.
Десктопное приложение сверяет новые слова на дубли по публичному `https://korean.meeymirita.ru/words.json` (после деплоя, кэш до ~15 минут). Публичного списка грамматики нет и по решению владельца не нужен. Таблица ошибок из тетради на сайт не вносится.

## Стек и запуск

Папки: `frontend/` (Nuxt 4, SSR, Vue 3, Pinia, `srcDir: 'src'`), `backend/` (NestJS 12 + Prisma + PostgreSQL, Node 22.18+ или 24.12+), `docker/` (Dockerfile, Caddyfile, Prometheus, Grafana), в корне `tests/`, `docs/`, `scripts/`, `.github/` и `package.json` только для тестов
(три отдельных `node_modules`; корневой нужен тестам, `scripts/link-test-deps.mjs` делает `vue` и `pinia` ссылками на копии из `frontend/`). **Пути `src/...` везде считай от `frontend/`.**

- Установка: `npm ci && npm --prefix frontend ci && npm --prefix backend ci && npm --prefix backend run db:generate` (Prisma Client; тестам нужны PostgreSQL, Redis, Meilisearch и `pg_dump` 17+: как поднять, в `docs/docker.md`, последний раздел).
- Из корня: `npm run dev` (сайт, порт 3000, `/api` → `API_PORT`), `npm run server:dev` (API, порт 3001), `npm run build`, `npm run type-check`, `npm test`.
- Хостинг: Docker Compose (`docker-compose.yml`): сайт `127.0.0.1:3000`, API `127.0.0.1:3001`, PostgreSQL, Redis, Meilisearch, Prometheus, Grafana; боевой Caddy сервера остаётся прежним и ходит на эти порты. Обновление: `bash scripts/deploy.sh` (копия базы, сборка, откат сам). Перенос данных, копии, мониторинг: `docs/docker.md`; Caddy, защита, диагностика: `docs/hosting.md`.

## Как проверять

- CI на GitHub (типы, сборка, тесты, `npm audit`, Node 22 как в образах Docker) идёт на каждый push; Dependabot раз в неделю предлагает обновления (крупные не сливать вслепую).
- Тесты: `npm test` (сборка сервера, Nest-тесты `backend/test`, Nuxt-тесты `frontend/test`, затем `tests/*.test.mjs`; около 700 тестов: 580 в `tests/` и около 125 во фреймворках). Отдельно `npm run test:nest`, `npm run test:nuxt`.
- Типы и сборка: `npm run type-check`, `npm run build`. Тест TS-модулей без браузера: `tests/_load.mjs` (`load('/src/...')`).
- Визуально: headless Chromium из кэша Playwright (`~/Library/Caches/ms-playwright/chromium_headless_shell-*/…/chrome-headless-shell`), `--screenshot` или `--remote-debugging-port`.
- Демо-сервер: `DATA_DIR=<tmp> PORT=3002 PROGRESS_TOKEN=… node backend/dist/main.js`, сайт `API_PORT=3002 npx --prefix frontend nuxt dev --port 5198`,
  данные `API=http://127.0.0.1:3002 TOKEN=… node scripts/demo-seed.mjs`. Скриншоты «О платформе» снимай только на демо-данных. Потом убери сервер и файлы.
- Вёрстка на телефоне: `TOKEN=… WIDTHS=320,390,768 node scripts/check-layout.mjs` (ничего не печатает, если всё в порядке); битые ссылки: `node scripts/check-links.mjs` (`BASE`, `TOKEN`, `EXTERNAL=1`).
- Swagger: `SWAGGER=1 npm run server` → `http://127.0.0.1:3001/api/docs` (только локально).
- На macOS нет `timeout` и `tac`; `sleep` в foreground блокируется: ждать через Monitor.
