# Docker и операционный мониторинг

Compose запускает сайт Nuxt, API NestJS, Caddy, Prometheus, Grafana и node-exporter. API и мониторинговые сервисы не публикуют порты наружу. Caddy обслуживает сайт и API. Внутренний адрес `/api/metrics` доступен Prometheus в сети Compose; через публичный Caddy маршрут закрыт.

## Первый запуск

1. Скопировать `.env.compose.example` в `.env`, задать длинные случайные значения для `POSTGRES_PASSWORD`, `REDIS_PASSWORD`, `MEILI_MASTER_KEY` и `GRAFANA_PASSWORD`. На сервере указать доменное имя в `DOMAIN`; для разработки подойдёт `localhost`.
2. Создать `backend/.env` из `backend/.env.example`, указать `PROGRESS_TOKEN` и используемые настройки почты/чата.
3. Создать каталог данных с владельцем пользователя `node` контейнера API (UID 1000): `mkdir -p backend/data && sudo chown 1000:1000 backend/data`.
4. Запустить `docker compose up -d --build`.

PostgreSQL и загруженные файлы хранятся в каталоге `APP_DATA_DIR` (по умолчанию `backend/data`); Redis и Meilisearch используют постоянные Docker-тома. Grafana привязана к `127.0.0.1:3002`: для доступа с другого компьютера использовать SSH-туннель. Prometheus хранит метрики 15 дней. CPU, память, файловые системы и время работы хоста поступают от node-exporter.

Для каждого Compose-сервиса задана проверка готовности. API владельца `GET /api/ops/services` и `GET /api/ops/logs/:service?tail=100` возвращают состояние контейнеров и последние строки стандартного журнала выбранного сервиса. Ограничение — от 1 до 500 строк. Запросы идут к Docker API через proxy, который разрешает чтение контейнеров и блокирует операции записи. Не публиковать его порт за пределы внутренней сети Compose. Эти маршруты требуют токен владельца: журналы могут содержать служебные подробности.

## Резервные копии

Сохранить текущий таймер `scripts/backup.sh` или запустить этот скрипт вручную. Рядом с `backup-status.json` он создаёт файл метрик `backup.prom`; общий каталог `APP_DATA_DIR` доступен сборщику текстовых метрик node-exporter. Панель Grafana показывает время последней удачной копии и статус последнего запуска. До первой копии эти поля будут пусты.

Операционная панель показывает скорость запросов, долю HTTP 5xx, задержку p95, загрузку CPU/памяти/диска хоста, доступность мониторинговых целей и статус резервной копии. Учебные действия, ошибки, время занятий и статистика ученика в Grafana не собираются.

## Поиск

PostgreSQL, Redis и Meilisearch входят в Compose. Их порты доступны только внутри сети проекта. Владелец запускает переиндексацию открытого учебного каталога из вкладки «Сервисы» кабинета. Ключ Meilisearch хранится только на backend. Заметки и другие личные данные в открытый индекс не передаются.

## Обновление

Пересобрать и запустить контейнеры: `docker compose up -d --build`. Остановить стек: `docker compose down`; постоянные данные приложения, PostgreSQL, Grafana, Prometheus и Caddy сохраняются в каталогах и Docker-томах. Перед восстановлением сервера сделать копии `APP_DATA_DIR` и именованных томов Compose.
