# Что сделано 2026-11-13 и как это проверить

Всё ниже сделано за один сеанс и лежит отдельными коммитами в `main` (по одному на действие). Описание каждой возможности в `docs/` обновлено, записи добавлены в «Историю» на сайте (`/history`).

**Важно перед проверкой.**
- Серверные тесты, которым нужна база (`TEST_DATABASE_URL`), локально не запускались: их прогонит CI. Миграция и серверные части заметок, корзины и напоминаний проверены только типами и тестами без базы.
- Вид на экране (браузер, телефон, тёмная тема) нигде не смотрелся. Ниже у каждого пункта написано, что именно посмотреть.
- После пуша выкладка идёт сама при зелёном CI. Если CI красный: `gh run list --limit 4`, потом `gh run view <id> --log-failed`.

## 1. Подборка слов в Telegram: «Выписать в тетрадь» в 19:00

- **Что.** В теме «Подборка слов» вместо «Проверь себя» сообщение «Выписать в тетрадь»: слово жирным и перевод открыто (без спойлера), чтобы переписывать в тетрадь. По умолчанию: включено, 19:00 по времени сервера, 8 слов и 5 предложений.
- **Где.** `backend/src/mail/templates.ts` (`digestMail`), `backend/src/digest/digest.service.ts` (значения по умолчанию), `docs/telegram.md`.
- **Как проверить.** Кабинет → «Настройки» → «Подборка» → кнопка проверки: в теме «Подборка слов» придёт сообщение с заголовком «Выписать в тетрадь».
- **Что учесть.** Если подборку уже настраивали и сохраняли, остаются прежние время и числа: новые значения работают только для несохранённых настроек. Поставить 19:00 и числа можно в тех же «Настройках».

## 2. Серия дней больше не сбивается

- **Что.** Вместо серии подряд счётчик «дней занятий» (число разных дней с ответами). «Лучшая серия» и рекорд «Самая длинная серия» убраны. Достижения «Три дня», «Неделя», «Месяц», «Сто дней» теперь за разные дни, а не подряд. Напоминание в Telegram больше не пугает обрывом серии.
- **Где.** `frontend/src/stores/progress.ts` (`studyDays`), `backend/src/progress/progress.service.ts`, `frontend/src/data/records.ts`, `achievements.ts`, `backend/src/reminders/reminder.service.ts`.
- **Как проверить.** «Обзор» и «Настройки»: подпись «дней занятий». Пропустить день в тестовых данных и убедиться, что число не упало (покрыто `tests/progress.test.mjs`).
- **Не проверено.** Серверные тесты с базой.

## 3. Экзамен: защита от потери ответов; «Ещё раз ошибки этой серии»

- **Что.** Пока часть экзамена не сохранена, закрытие вкладки и уход со страницы спрашивают подтверждение. После «Сохранить часть» и «Сохранить и выйти» вопрос не появляется. На итоге серии заданий есть кнопка «Ещё раз ошибки этой серии» (только если были ошибки).
- **Где.** `frontend/src/components/korean/ExamRun.vue`, `views/korean/ExamView.vue`, `components/korean/TaskSession.vue`.
- **Как проверить.** Начать экзамен, ответить на пару пунктов и закрыть вкладку: браузер спросит. Пройти серию «5 минут» с ошибкой: на итоге появится кнопка.
- **Посмотреть глазами.** Вид кнопки на итоге; окно «Ответы не сохранены»; кнопка «Назад» в браузере.

## 4. Скачать мои слова (CSV)

- **Что.** Кнопка «Скачать мои слова (CSV)» в «Настройках» рядом с копией прогресса. Поля: слово, чтение, перевод, очки, верных, ошибок, выучено. Берутся слова из заданий, по которым были ответы, и слова, которые записал сам. Гостю недоступно.
- **Где.** `backend/src/wordsexport/` (эндпоинт `GET /api/words/export`), `scripts/words-export-vocab.mjs`, `frontend/src/components/cabinet/SettingsTab.vue`.
- **Как проверить.** «Настройки» → «Скачать мои слова»: придёт файл `my-words-<дата>.csv`. Открыть в Excel (с русскими настройками может открыться одной колонкой: «Данные → Из текста/CSV») или импортировать в Anki.

## 5. Закрепление слов по темам («Добить тему»)

- **Что.** На странице «Слова» у каждой темы полоска «выучено N из M» и кнопка «Добить тему»: серия до 10 заданий только по ещё не выученным словам, самые слабые первыми. Выучено = очки слова не меньше 5.
- **Где.** `frontend/src/data/korean/topics.ts`, `views/korean/WordsView.vue`.
- **Как проверить.** «Слова» (без поиска и фильтра «Важное») → блок «Закрепление по темам» → «Добить тему».

## 6. Тренажёр «Переведи и объясни»

- **Что.** Серия из 15 предложений (4 варианта перевода), после ответа показывается разбор по словам и список правил предложения с кнопкой «Открыть правило». Предложения только из пройденного.
- **Где.** `frontend/src/views/korean/ExplainTranslateView.vue`, `data/korean/translate-explain.ts`, `docs/trainers/explain.md`.
- **Как проверить.** «Игры» → группа «Построение предложений» → «Переведи и объясни» (`/game/home?game=explain`).
- **Замечание.** У правила множественного числа (`deul`) подходящее предложение одно, оно будет часто попадаться. Для разнообразия нужны 1–2 новых предложения (только по твоему слову).

## 7. Страница обслуживания на время деплоя

- **Что.** Пока сайт перезапускается, вместо ошибки соединения показывается тихая страница «Сайт обновляется» (пастельная, сама обновляется каждые 15 секунд, не кэшируется браузером; для `/api/*` отдаётся JSON 503).
- **Где.** `docker/caddy/maintenance.html`, `docker/caddy/Caddyfile`, `docker-compose.yml`, `docs/hosting.md`.
- **Нужно сделать руками на сервере.** Боевой Caddy стоит вне репозитория. Скопировать `maintenance.html` в `/var/www/maintenance/`, вставить блок `handle_errors` из `docs/hosting.md` в `korean.meeymirita.ru`, затем `caddy validate --config /etc/caddy/Caddyfile && systemctl reload caddy`.
- **Как проверить.** `docker compose stop frontend`, открыть сайт, потом `docker compose start frontend`. В Docker-стеке с профилем `edge` страница подключена сама (проверено на образе `caddy:2-alpine`).

## 8. Вырезка из текста

- **Что.** Страница `/korean/clip` (закрыта токеном): вставляешь корейский текст (до 2000 знаков), слова подсвечиваются. Зелёный: выучено; золотистый: есть в словаре, но не выучено; голубой пунктиром: есть только в большом словаре; серый: не найдено. Перевод по нажатию, счётчик «известно N из M». Текст нигде не сохраняется.
- **Где.** `frontend/src/views/korean/ClipView.vue`, `data/korean/clip.ts`, `data/korean/parse.ts` (поле `lemma`).
- **Как проверить.** Меню → «Вырезка» → вставить любой текст со словами из словаря.
- **Не проверено.** Запросы к большому словарю на боевых данных.

## 9. «Важное»: потренировать отмеченные слова

- **Что.** На странице «Важное» кнопка «Потренировать важные слова»: серия до 15 заданий по словам со звёздочкой (нужно хотя бы 4 слова из заданий). Подбор слов общий с «Добить тему» (`drillTasks` в `topics.ts`).
- **Где.** `frontend/src/data/korean/marks-drill.ts`, `views/korean/MarksView.vue`.
- **Как проверить.** Отметить 4+ слова звёздочкой на «Словах» → «Важное» → кнопка.

## 10. Заметки: закрепление, корзина 30 дней, напоминание в Telegram

- **Что.**
  - Булавка закрепляет заметку сверху списка.
  - Удалённые заметки и картинки 30 дней лежат в «Корзине»: «Восстановить» или «Удалить навсегда» (второй раз просит токен). Раз в сутки в 03:40 просроченное стирается само.
  - В окне заметки поле «Напомнить в» (по времени сервера): в это время заголовок и начало заметки приходят в Telegram в тему «Напоминания» (один раз; просроченное при простое сервера досылается не старше суток).
- **Где.** `backend/src/notes/`, `backend/src/images/`, `backend/src/trash/`, `backend/prisma/migrations/20261113120000_notes_pin_trash/`, `frontend/src/components/cabinet/NotesTab.vue`, `NoteModal.vue`, `ImagesTab.vue`, `TrashPanel.vue`.
- **Миграция.** Только добавление столбцов: `notes.pinned`, `notes.deleted_at`, `notes.remind_at`, `notes.remind_sent`, `images.deleted_at`. При деплое накатится сама (`scripts/deploy.sh` делает копию базы заранее).
- **Как проверить.** Закрепить заметку; удалить заметку и картинку, открыть «Корзина (N)», восстановить; поставить напоминание через 2 минуты и дождаться сообщения.
- **Не проверено.** Настоящая база, настоящая отправка в Telegram, вид на телефоне. Тесты `tests/notes-trash-server.test.mjs` и `tests/images-server.test.mjs` написаны, но прогонит их CI.
- **Решения.** Вложения заметок и обложка стираются сразу, в корзину идёт только раздел «Картинки». Место на диске в «Настройках» считается вместе с корзиной.

## 11. Напоминание о незаконченном экзамене

- **Что.** Если сохранена хотя бы одна часть экзамена, но не все, и черновик не менялся 3 суток, раз в сутки приходит сообщение в тему «Напоминания» с кнопкой «Продолжить». Если экзамен сдан или не сохранено ни одной части, напоминания нет.
- **Где.** `backend/src/exams/draft-remind.ts`, `exams.service.ts`, `backend/src/mail/templates.ts` (`examDraftMail`).
- **Как проверить.** Тесты без базы: `cd backend && npx vitest run test/exam-draft-remind.spec.ts`. В живом режиме нужно ждать трое суток.

## 12. Избранное в большом словаре `/dict`

- **Что.** У слов на `/dict/<слово>` звёздочка (видит только владелец с токеном). В «Важном» блок «Из большого словаря» со ссылками. Метки `k:<слово>` лежат в тех же `settings.marks`, лимит 500 прежних меток и 500 таких.
- **Где.** `frontend/src/components/dict/DictStar.vue`, `lib/marks.ts`, `views/DictWordView.vue`, `backend/src/progress/progress.service.ts`.
- **Как проверить.** Войти по токену → `/dict/사람` (или любое слово) → звёздочка → «Важное» → блок «Из большого словаря».

## 13. Недельная цель

- **Что.** В «Сегодня» кольцо недели: «Неделя: 3 из 5 дней, 64 из 100 верных». Цель настраивается в «Настройках» («Цель недели»: по умолчанию 5 дней и 100 верных). Воскресный PDF-отчёт в Telegram начинается строкой про цель недели.
- **Где.** `frontend/src/data/weekgoal.ts`, `components/korean/WeekGoalRing.vue`, `views/korean/TodayView.vue`, `backend/src/study/week-goal.ts`, `weekly-pdf.ts`.
- **Как проверить.** «Сегодня» → кольцо вверху; в кабинете `Telegram` кнопка «Отчёт за неделю сейчас», посмотреть PDF.
- **Посмотреть глазами.** Расположение строки цели в PDF (график сдвинут на 10 пикселей вниз).

## 14. «Обзор»: фильтр слабых слов по теме и «Давно не видел»

- **Что.** Над слабыми словами выбор темы. Ниже список слов, по которым последний ответ был больше 30 дней назад (самые давние первыми, по 20 строк), и кнопка «Повторить их» (серия до 15 заданий).
- **Где.** `frontend/src/data/korean/stale.ts`, `components/cabinet/OverviewTab.vue`.
- **Как проверить.** Кабинет → «Обзор». Блок появится, когда есть слова с ответами старше 30 дней.

## 15. Тренажёры «Цепочки слов» и «Определи часть речи»

- **«Цепочки слов».** Как 끝말잇기: выбрать слово, которое начинается с последнего слога предыдущего; 12 звеньев, перевод после ответа. Слов хватает (372 опорных, цепочки находятся всегда). `chain.ts`, `ChainView.vue`, `docs/trainers/chain.md`.
- **«Определи часть речи».** 15 заданий по глаголам, прилагательным и вопросительным словам, после ответа объяснение и пример. Существительных нет: в словаре нет разметки части речи. `part-of-speech.ts`, `PartOfSpeechView.vue`, `docs/trainers/speech.md`.
- **Как проверить.** «Игры» → группа «Словарный запас» → оба тренажёра (`?game=chain`, `?game=speech`).
