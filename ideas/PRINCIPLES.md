# Принципы: что нельзя ломать

Каждая идея в этой папке проходит проверку этими правилами. Если идея с ними спорит, она либо меняется, либо уходит в «не будем».

## Решения владельца
- **Звука нет и не нужно.** Никаких озвучек, кнопок «послушать», аудирования. Вместо звука: транскрипция русскими буквами, схемы артикуляции,
  минимальные пары и правила чтения текстом, письмо рукой. Если решение изменится, идеи про звук лежат в разделе «Отложено» (`ROADMAP.md`).
- **Никаких японских и китайских знаков**, даже в пояснениях (в том числе ханча для корейских слов). Декоративные и учебные надписи хангылем.
- **Не забегать вперёд пройденного.** Пройдены уроки 1–11 и прошедшее время. Будущее время не используем, пока не пройдено. Новые уроки появляются
  в уроках, словаре и заданиях только когда владелец их отметит пройденными (идея `C1`: «граница пройденного»).
- **Пол не угадываем.** В русских переводах «я» нейтрально («ходил(а)»), в интерфейсе обращаемся без родовых форм («получилось», «напиши»).
- **Вид:** пастельный розово-голубой стиль по макетам владельца, название **우리말**, стрелки простые `→`, смайликов в строках управления нет.
- **Ответ коротко:** что сделано, что проверено, что осталось. Правки по одной, с скриншотом.
- **Коммиты и пуш только по просьбе**, отдельными коммитами, каждый проверен.

## Технические правила
- **Пакеты ставить можно, любые и сколько нужно (решение владельца 2026-10-30)**, если они дают интерактивность и пользу: графики, редактор заметок, анимации, PWA, конфетти,
  даты, перетаскивание и так далее. Корневой `node_modules` теперь **свой** (отвязан от соседнего проекта 2026-10-30), ставь обычным `npm install <пакет>`, затем `npm test`,
  `npm run build`. Серверные пакеты: `npm --prefix server install …`.
- **Выбирая пакет, смотрим:** размер в сборке (важно для скорости и SEO), живой ли проект и свежие ли релизы, `npm audit` после установки,
  не тащит ли лишнее, работает ли с пререндером (`scripts/prerender.mjs` грузит данные в Node без браузера). Тяжёлое грузим лениво (`import()`).
- **Запросы только через `fetchT`**, подтверждения через `askConfirm`, опасное действие через `askTokenDo`, результат через плашку.
- **Всё, что стирает данные, просит токен ещё раз** (проверяет сервер).
- **Окна поверх страницы в `Teleport` и с правильным слоем** (подтверждение 500, плашки 600, просмотр картинки 300, окно заметки 60, поиск 45, окно грамматики 50).
- **Тесты на новую логику обязательны** (`npm test`). Данные страницы, которую должны видеть роботы, добавляем в `seo.ts`, `sitemap.xml`, `prerender.mjs`.
- **Новая страница = новый слайд в «О платформе»** и строка в шторке «Что здесь есть».
- **Гость ничего не сохраняет**, картинки и база только у владельца; любая новая «личная» вещь обязана это уважать.
- **Токен нигде, кроме `server/.env`**, и не показывается.
- **Данные не должны теряться:** любая миграция базы идёт через `Db.migrate` и проверена тестом на «старой» базе.

## Критерии хорошей идеи
Она сокращает путь между «захотел» и «сделал» (меньше кликов), либо помогает запомнить (повторение, ошибки), либо создаёт повод вернуться
завтра (серия, события, цели), либо делает платформу «твоей» (личные данные, оформление, коллекции).
