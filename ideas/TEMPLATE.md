# Шаблон идеи

```
### X00. Название · [Новое | Улучшение] · размер S/M/L/XL · ценность ★…★★★★★
**Сейчас:** что уже есть по теме (или «нет»; смотри CURRENT.md).
**Предлагаю:** как это выглядит для пользователя, в одном-двух предложениях.
**Как сделать:** какие файлы, таблицы, пакеты; нужна ли миграция; какие тесты; что в `seo.ts`, `about.ts`, `guide.ts`.
**Риски:** что может пойти не так (данные, скорость, ограничения из PRINCIPLES.md).
```
Номера: L learning, P personal, G gamification, T tools, C content, S teacher/social, A ai, D design, X tech.
