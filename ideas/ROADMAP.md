# Дорожная карта

Идеи разложены по волнам: сначала то, что дёшево и сразу заметно, потом то, что меняет привычки, потом большие проекты. Внутри волны порядок примерный,
выбирай по настроению и по тому, что болит. Статус в колонке: `идея` · `в работе` · `✅`.

## Волна 0. Подготовка ✅ сделано 2026-10-30

Сделано: `node_modules` отвязан от соседнего проекта (пакеты теперь ставятся свободно), автопроверки на GitHub (`.github/workflows/ci.yml`), Dependabot (`.github/dependabot.yml`), автодеплой
`bash scripts/deploy.sh` с откатом. Осталось из этой волны: CSP для сайта (`X10`, строка в Caddy) и защита ветки `main` на GitHub (настройки репозитория).

| Что | Зачем |
|---|---|
| Отвязать `node_modules` от соседнего проекта (`rm node_modules && npm install`, потом `npm test` и `npm run build`) | можно ставить пакеты, не ломая другой проект (см. `PRINCIPLES.md`) |
| `X11` автопроверки на GitHub, `X12` автодеплой одной командой | каждая следующая волна выкладывается без ручных шагов и забытых команд |
| `X10` Dependabot и CSP для сайта | безопасность растёт вместе с пакетами |

## Отложено
Всё, что связано со звуком (озвучка слов и фраз, аудирование, произношение с записью): владелец решил, что звук не нужен. Если решение изменится, начать
с озвучки словаря и фраз дня, затем аудирование в играх. Пока в идеях звука нет.

## Не будем
Японские и китайские знаки в любом виде (в том числе ханча для корейских слов). Реклама и сторонние трекеры. Забегание вперёд по программе без явной отметки «пройдено».
