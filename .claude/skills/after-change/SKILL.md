# После правки: по порядку, ничего не пропускай

**Правило владельца (2026-11-17): изменил или добавил что-то в одном месте, обнови ВСЕ места из карты ниже, в том же коммите и в том же ответе.** Нашёл по пути расхождение (устаревшее «не пройдено», старое число слов, другое название): чини сразу и назови в ответе, не оставляй «потом». Сомневаешься, где ещё это упомянуто: `grep -rn "<слово или id>" frontend/src backend/src tests scripts docs CLAUDE.md README.md .claude/skills`.

## Карта: что менялось → где ещё это живёт
- **Слово или перевод** (`dictionary.ts`, `translations.ts`): `npm run sync` обновит всё производное (слова попадают в инструкции чата и голоса через `KNOWN_WORDS` и `KNOWN_READINGS`, число слов в README и `docs/data.md` тоже); руками остаются сценки голоса (`voice/scenes.ts`, слова только из словаря); тесты `words-json`, `parse`, `exam-data`, `readme`.
- **Новая или изменённая грамматика**: `bk` (место в книге 1A/1B), заглушка `ahead` на ту же тему превращается в карточку (не дубль), `npm run sync`, `node scripts/build-wine-components.mjs` при новом CSS, правило в `rules.ts` и `TRAPS`, `HISTORY`, `docs/data.md` (число заглушек и список), локальные `КАРТА.md` и `plan-new.md`; «Карта обучения» и вкладка «1B» обновятся сами из карточек (полный список в `CLAUDE.md`, «Правила кода»).
- **Статус карточки грамматики** (`st: 'ok'` или `soon`, правило карточки): `npm run sync` (в обе инструкции чата и голоса «пройдено» попадает из карточек, а «не пройдено» из своих непройденных карточек, в том числе заглушек «впереди» (`ahead` в `grammar.ts`); **статусы в `prompt.ts` и `CLAUDE.md` руками не писать**, раньше они расходились). Тема, которую ещё не проходили: карточка-заглушка `ahead: true` во «Моих карточках» (тест `tests/ahead.test.mjs` ловит «и пройдена, и впереди»); зависимость в `lab.ts` (`DEPS`). «Пройдено» одно для всего сайта: только `st` (личные кнопки «Снять отметку» и «Отметить пройденным» убрали 2026-11-17, `tests/single-status.test.mjs` следит). Снять или поставить `ok` может только Claude по слову владельца.
- **Режим или тренажёр**: `MODES`, `MODE_HELP`, `build-mode-names`, `docs/trainers/<режим>.md`, `docs/games-catalog.md`, `docs/game.md`.
- **Страница**: `seo.ts`, `crumbs.ts`, `guide.ts`, `sections.ts`, слайд в `about.ts`, `docs/home-and-theme.md`.
- **Сервер, база, настройки**: миграция Prisma, `docker-compose.yml`, `.env.example`, `backend/src/config.ts`, `docs/server.md` и документ по теме (`docs/voice.md`, `docs/chat.md`), перезапуск сервера после выкладки.
- **Инструкция голоса или чата** (`voice/prompt.ts`, `chat/prompt.ts`): правило, добавленное в одну, проверь и в другой (у них общие `KNOWN_*`, но проза своя); обе описаны в `docs/voice.md` и `docs/chat.md`; тесты `voice-util.spec.ts` (предел длины) и `chat-prompt.test.mjs`; правку инструкции голоса прогоняй через `scripts/voice-text-check.mjs` (20 сценариев, нужен ключ, см. `docs/voice.md`), новую живую ошибку добавляй туда сценарием.
- **Любое заметное изменение**: запись в начало `HISTORY` **и сразу `npm run growth`** (страница `/growth`: график, число коммитов и строк кода лежат только в `data/growth.ts`, не входит в `npm run sync`; тест `tests/growth.test.mjs` падает, если график отстал от «Истории» больше чем на день). Числа слов, правил и игр на `/growth` берутся живьём из данных, их руками не трогать.
- **Входящие и API** (`materials`, `learning`, `rules.ts`, токены): `docs/data.md` («Входящие»), `docs/server.md`, `docs/desktop-skill.md`, вкладка «Инструкция» в `InboxPanel.vue` (`HELP`), `scripts/inbox.mjs`; новый урок проверки: правило в `rules.ts` и строка в `docs/data.md`.


Ноутбук слабый: одна тяжёлая команда за раз, ничего параллельно.

1. **Производные файлы: одна команда `npm run sync`** (словарь, переводы, грамматика, статус карточки, режим, заглушки `ahead`, `dark.css`). Она обновляет пул писем, `words.json`, инструкции чата и голоса (пройденное и «не пройдено»), открытые данные для чтения, названия режимов, `night.css` и числа слов и правил в README и `docs/data.md`. `npm run sync:check` только проверяет; тест `tests/sync.test.mjs` падает, если забыли. Вручную остаётся: страница (слайд и скриншот в «О платформе»: `src/data/about.ts`, `scripts/about-shots.mjs`).
2. **Описание**: поправь `docs/` по теме (для тренажёра `docs/trainers/<режим>.md`, для каталога `docs/games-catalog.md`). Расходится с кодом: верь коду.
3. **История и рост**: запись в начало `HISTORY` (`frontend/src/data/history.ts`), тест следит за форматом; **потом `npm run growth`** (обновляет `/growth`; без этого тест роста краснеет).
4. **План**: локальный `plan-and-fixes/plan-new.md` (не в git): статус вверху ✅ / ⏳ / ❌, сделанное из разделов удали, новое допиши.
5. **Тесты по одному файлу**:
   - данные и скрипты: `node --test --test-concurrency=1 tests/<файл>.test.mjs`;
   - сайт: `cd frontend && npx vitest run test/<файл>.spec.ts --maxWorkers=1`;
   - сервер без базы: `cd backend && npx vitest run test/<файл>.spec.ts`;
   - потом `npm run type-check` и `npm run lint`.
   **Новая функция, страница, тренажёр или режим: перед пушем ещё `npm run test:quick` целиком** (около минуты): в нём живут сверки списков (каталог игр, чек-лист, SEO, закрытые страницы, документация), которые не видны по затронутым файлам; 2026-11-17 из-за этого два пуша подряд дали красный CI. `tests/nuxt-ssr.test.mjs` и серверные тесты с базой идут только в CI (нужны сборка сайта и база).
   Смотри `ℹ fail 0` или `Tests N passed`. Упал тест без базы: чини, не коммить. Упал только тест с `TEST_DATABASE_URL`: не твоя ошибка, скажи об этом.
   Менялись только текст, документация, картинка или `.env.example`: тесты не гонять.
6. **Коммит**: одно действие, один коммит; сообщение на английском, повелительное; в конце строка `Co-Authored-By:` своей модели. Не коммить `plan-and-fixes/`, `материалы/`, временные файлы, `.env`.
7. **Пуш в `main`**, потом `gh run list --limit 4`. Красный CI: `gh run view <id> --log-failed` и чини сам.
8. **Ответ владельцу** коротко и по-русски: что сделано, что проверено, что **не** проверено (вид на телефоне, iPad, боевой сервер: попроси посмотреть), что осталось. Напомни: выкладка пойдёт сама после зелёного CI. Без родовых форм о владельце.
