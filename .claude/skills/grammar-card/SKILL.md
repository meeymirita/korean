# Карточки из материалов

Правка в одном месте требует правки во всех связанных: смотри карту «что менялось → где ещё это живёт» в скилле `after-change`.

Тему и порядок задаёт только Лера. Сам новых тем не добавляй и не предлагай. Работа идёт **только во вкладке «Мои карточки»**: «Часть 1» и «Часть 2» не трогать и не сверять с ними.

1. Прочитай `docs/data.md` и `src/data/korean/grammar.ts`, потом PDF из `материалы/ГГГГ-ММ-ДД/` (локально, не в git).
2. **Дополняй** существующую карточку, а не переписывай: что есть, оставь, добавь недостающее (ошибки, сравнения, порядок слов).
3. Новая карточка: без подписи урока `l` и без видео, статус `st: 'soon'`. Карточка = видео только для карточек урока.
4. `st: 'ok'` ставь **только по слову владельца** («отметь пройденной»).
5. Предложения и переводы сверь со скиллом `check-sentences`; «я» без рода. Сомнительное скажи владельцу, не вноси молча.
6. Слова и имена из материалов вносятся на сайт только по слову владельца (скилл `new-words`).
7. После смены статуса или словаря: `node scripts/chat-curriculum.mjs`, `node scripts/digest-pool.mjs`, `node scripts/build-study-data.mjs`, при новых словах ещё `node scripts/build-words-json.mjs`. Дальше `after-change` (тесты, коммит, пуш, напомнить про деплой).
