# Новые слова

Правка в одном месте требует правки во всех связанных: смотри карту «что менялось → где ещё это живёт» в скилле `after-change`.

Слова лежат в таблице `new_words` и берутся **только через API**. Токен не записывай в файлы и репозиторий и не печатай.

1. Владелец нажимает «Создать токен» в шторке «Новые слова» (10 минут, только чтение) и присылает токен в чат.
2. Прочитай: `INBOX_TOKEN=<токен> BASE=https://korean.meeymirita.ru node scripts/inbox.mjs`. Скрипт под каждым словом печатает перевод, часть речи и уровень из 한국어기초사전 (большой словарь сайта, наружу запросов нет).
3. Сверь: дубли (`/words.json` и `src/data/korean/`), перевод, часть речи, уровень. Заметки читай и разбирай с владельцем (`docs/data.md`).
4. **Обсуди расхождения**, скажи, что именно сомнительно. Не вноси молча.
5. **Добавляй в словарь только по слову владельца** («добавляй», «давай»). Сам слова для заданий не дописывай: не хватает слов, скажи, что и зачем нужно.
6. После добавления: `npm run sync`; тесты `tests/exam-data.test.mjs` и `tests/parse.test.mjs` по одному; затем скилл `after-change`.
7. Задания берут слова из `STUDY` (`src/data/korean/study.ts`), не из `D`; «дополнительные» абстрактные слова (`EXTRA`) в задания не идут.
8. Не забегай вперёд пройденного: смотри `st: 'ok'` в «Мои карточки»; пройдены уроки 1–11, прошедшее время, будущее `-(으)ㄹ 거예요`, частица `만`.
9. Переводы «я» без рода («ходил(а)»); транскрипция без лишнего `ъ`. Перед внесением сверься со скиллом `check-sentences`.
