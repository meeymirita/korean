# Проверка предложений и заданий

Полный список с примерами: раздел «Проверка нейросетями: чему научились» в `docs/data.md` (читай его, это краткая выжимка). Порядок проверки большого материала нейросетями: локальный `материалы/проверки/README.md`.

Для каждого пункта проверь:
- **«Я» без рода**: в переводе нет окончаний `-ец`, `-ла`, `-л` для «я» (`미국 사람이에요` = «Я из США»).
- **Один верный ответ**: нет второго верного варианта, который программа не принимает (`은/는` ↔ `이/가`, `하고/와/과`, `뭐` ↔ `무엇`, порядок групп с частицей).
- **Частицы**: `저는`, не `저가` (`제가`); `나는`/`내가`, `너는`/`네가`; `와/과` по 받침 (после гласной `와`, после согласной `과`; пройдено вместе с `하고`; в пропуске, где подходят и `하고`, и `와/과`, второго верного ответа не оставляй).
- **Счётное слово** только с числительным (`한 개`), `마트` = супермаркет, отрицание `없어요` (не `안 있어요`); у глаголов на `하다` `안` стоит перед `하다`: `공부 안 해요`, не `안 공부해요`.
- **Только пройденное**: без `-아/어서`, `-(으)ㄹ게요`, `-게 되다`, `에게/한테`, `(으)로`, `(으)ㄴ`, `그러니까`; `그` = «тот», не «он»; `앉아요` = «садится».
- **Без плеоназма и абсурда**: не «и … тоже» вместе; вещь и действие сочетаются (молоко пьют).
- **Слова**: `학생` = «ученик» (для вуза «студент»), `대학생` = «студент», `동생` = «младший брат/сестра».
- **Транскрипция**: без лишнего `ъ`; `ㄹ` после `ㅇ/ㄱ/ㅁ/ㅂ` читается `н`.
- **«Неверный» вариант** проверь отдельно: он действительно неверный. Имена только из списка героев учебника.
- **Нейросети**: принимай замечания, которые называют две и больше, или очевидные; одиночное спорное проверяй сам. `밑, 나, 너, 맥주, 소주, 사이다, 이거/저거` в словаре есть.

После внесения: `node --test --test-concurrency=1 tests/exam-data.test.mjs`, затем `tests/parse.test.mjs`. Задания берут слова из `STUDY`, не из `D`.
