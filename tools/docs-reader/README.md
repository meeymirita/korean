# Читалка документации

Одна красивая страница из всех файлов `docs/`: меню слева по группам, поиск по всему тексту (клавиша `/`), оглавление справа, светлая и тёмная тема, переходы между файлами.

```
cd tools/docs-reader
npm install
node build.mjs
```

Получится `index.html` (не в git): открыть двойным щелчком, интернет не нужен. После правки `docs/` собрать заново. Зависимость одна, `marked`, вставляется прямо в страницу.
